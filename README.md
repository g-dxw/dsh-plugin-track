# 轨迹

易宝工坊 / DeepSeek Harness 的轨迹插件。导入 **GPX / KML / TCX**，查看二维、3D 地图、卫星和精细 3D 沙盘，编辑轨迹，在 SVG 画布添加点位、排版照片并导出路线图，也可录制轨迹动画。

侧栏 **易宝工坊 → 轨迹**。通过官方 `sidebar.panellist` 和 `main` 插槽挂载，保留原有对话界面。

界面跟随易宝工坊的浅色/深色模式、自定义配色、强调色、字号和圆角设置。主题切换即时更新控件与海拔图，保留图表数据、缩放和游标位置。SVG 分享画布采用浅色路线图样式，标记颜色可在点位抽屉调整。

## 使用

1. **导入**：把 `.gpx` / `.kml` / `.tcx` 拖进面板，或点「选择文件」。默认名称使用文件名去掉最后的扩展名，例如 `峨眉山.kml` → `峨眉山`；文件内部的路线名称不覆盖此默认值，KML 点位名称独立保留。可以一次选多个；单个文件上限 8 MB，解析出的轨迹点上限 50 万。
2. **看**：列表按导入时间倒序。点一条进入详情，默认显示二维地图，下面是海拔剖面与统计卡片。点击「3D 地图」启用真实高程、山体阴影和天空，首次倾角 60°，支持旋转、缩放、重置和视角恢复；编辑和拾点使用二维。点击「3D 沙盘」查看区域山体起伏、贴地轨迹和起终点；拖动旋转、右键拖动平移、滚轮缩放，也可用按钮放大、缩小和重置视角。「光影」可即时调节太阳方位、高度、主光、环境光和阴影，支持键盘操作及恢复默认。底图栏保留「矢量 / 地形 / 卫星 / 无底图」，「其他地图源」可选 OpenStreetMap 与 MapTiler。
3. **导出**：
   - **导出原文件** —— 拿回你当初导入的那个文件，**逐字节一致**（面板保留了一份 `source.<ext>`，不是重新序列化出来的）。
   - **导出 GeoJSON** —— 标准 `FeatureCollection`，`LineString` + 起终点 `Point`，可以丢进 geojson.io / mapshaper / QGIS。
4. **删除**：轨迹列表右侧和详情页都有删除入口。确认弹窗显示轨迹名称；确认后删除应用内的轨迹、标注、动画脚本和视频脚本缓存，电脑上的原始文件和导出文件保留。删除失败可重试。


## 中文地图镜头编辑（本地集成原型）

在轨迹详情进入「轨迹视频制作」→「镜头编辑」→「地图」，可将真实分段路线与已保存地名生成 GeoMotion 工程。地图和 3D 沙盘共用工作台，保留各自工程。多轨时间轴共用秒刻度与播放头，可拖动关键帧、移动片段、拖动两端裁剪、缩放或适应全长。支持按帧吸附、方向键微调、秒数输入、播放、撤销重做和 JSON 备份。

在「轨迹视频制作」切换到「素材准备」，先从真实轨迹、有效点位/分组、已保存 SVG 和关联图片提取素材，并查看资源库选用清单。确认展示标记、沿路线补点、拆分/合并路线、选择照片、编辑分段介绍和路线信息，再点「用所选素材编排镜头」。素材保存为独立草稿；带入地图镜头时保留相机构图和输出配置，可撤销恢复原工程。

每条轨迹独立保存工程，来源变化时可手动重建。工程底图随工程保存，地图服务和地形配置继续共享。导出把地图、地名、文字和署名合成后，以固定时间戳编码 VP9 WebM，可选择横/竖屏、帧率并取消导出。当前未接音乐、旁白混音与 MP4。

[集成说明](docs/geomotion-integration-plan.md)、[运行验收](docs/geomotion-integration-validation.md)、[多轨时间轴验收](docs/geomotion-timeline-validation.md)与[二维素材验收](docs/video-materials-validation.md)记录具体边界。GeoMotion 上游源码未声明许可，当前为开发分支原型，正式随产品分发前需要明确许可。

可复用的[武功山位置介绍示例](examples/wugongshan-location-preview/README.md)展示区域定位、推进真实山体与路线绘制，工程及图层时间均可编辑；大型视频和运行缓存由本地生成。

## 左侧 Agent 对话

在轨迹列表、线路详情或新建路线页，点顶部「Agent」打开左侧 DSH 原生对话。每条已保存轨迹按稳定的 `track.id` 使用独立项目目录和会话；顶部显示轨迹数量、当前页面、当前线路和完整轨迹编号。Agent 打开时切换线路会切到对应项目，返回原线路恢复自己的对话和未发送草稿；同一线路内切换详情和编辑页面继续使用同一会话。轨迹列表和未保存的新路线使用公共「轨迹」工作区。关闭再打开、重启后恢复对应项目的有效会话。

需要支持通用左侧 Agent 抽屉的易宝工坊 Desktop 扩展或增强布局。较宽窗口并排显示，窄窗口改为左侧覆盖层；原生输入框、模型选择和发送、停止控件由宿主提供。兼容布局或旧壳版本会禁用入口并说明原因。升级本地插件和 Desktop 后需要重新启动应用。

每个项目内的 `track-context.json` 随该线路页面更新参考快照，`AGENTS.md` 指示 Agent 回答当前范围的问题前读取它。项目目录以轨迹编号固定，线路改名不改变目录。摘要展示与工作区文件同步已接入；未保存路线内容、选中的标注点和分组尚未同步。当前尚未接入轨迹、标注点和分组的 Agent 编辑工具。原公共工作区及更早的逐线路工作区、历史会话和文件保留，不自动搬移或归入其他轨迹。

## 概览、编辑、标注与动画

- **轨迹概览**：左侧地图，右侧 KML 标注点列表，展示缩略图、编号、非空名称、海拔和时间。地图标记为小尺寸编号点；点击地图标记或列表项，直接弹出按照片原始比例显示的详情，标题、说明、时间、海拔、坐标和「查看大图」浮在照片底部，渐变底衬保证文字清楚。没有标题或说明时隐藏对应内容，仍保留点位；点击照片或「查看大图」打开大图，关闭后返回原点位。无图片或图片加载失败时正常展示文字信息。列表缩略图延迟加载，详情照片在选中点位后加载，单张失败可重试。已有 KML 记录从保留的原文件恢复点位及其时间、海拔；地点不计入轨迹里程。
- **基础统计**：距离计入文件海拔对应的坡面长度；海拔先做五点中值滤波，再累计爬升与下降，缺失海拔不会当作零。最高/最低点使用原始海拔。时长优先使用轨迹点时间，缺失时读取 KML 明确标注单位的总览耗时；显示到秒。运动均速按距离除以该时长计算，包含耗时中的停留；没有可靠时间时显示「-」。旧导入轨迹重新打开时从保留的本地原文件重算，保留名称、点位与原文件。
- **海拔图标注点**：标注点按最近轨迹位置显示在海拔曲线上，编号与地图、右侧列表一致；点击后选中同一地点并打开地图详情，地图和列表选中时图上同步高亮。密集点合并显示，展开后可选择具体点位；缩放或平移图表时标记随曲线更新。
- **编辑轨迹**：详情点「编辑当前轨迹」，默认进入「标注点编辑」，可切换「SVG 标注」和「线路编辑」；切换标签保留线路与画布草稿，退出时统一提示未保存修改。列表页点「新建路线」仍直接进入线路编辑。「线路编辑」支持连点、拖点、手绘补线、插入/删除、两点直连、内部点拆分、库中轨迹按列表顺序合并、反向、撤销/重做；也可用点序号和经纬度表单操作。线路保存结果是新 GPX 副本，原轨迹与原文件保留；拆分副本一起保存，失败回滚本批新副本，草稿保留。新增/移动点的海拔与时间为空，未动点保留原元组数据；海拔缺口不会画成海平面。
- **标注点编辑**：在「编辑当前轨迹」中编辑名称、描述和多选类型，调整点位、分组及显隐。Ctrl / Cmd 点击多选已有分组后，点击「合并分组」或使用右键菜单；按列表顺序保留第一个分组的名称，描述用空行连接，原始子点和图片保留，支持撤销/重做。点击分组行或展开按钮，会在地图原坐标显示子点；收起时隐藏子点，已隐藏的组和子点仍遵循显隐设置。图片可以填写 HTTP(S) 链接，也可以通过「添加本地图片」选择文件；支持 JPEG、PNG、WebP、GIF、AVIF，单张上限 20 MB，每个点位最多 30 张。上传成功后点击保存才关联到点位，本地图片复制到该轨迹目录；刷新、分组轮播和撤销/重做沿用同一图片引用。
- **SVG 标注画布**：从「编辑当前轨迹 → SVG 标注」进入，概览不再提供独立画布入口。左侧为轨迹画布，右侧为点位列表；点击或添加点位打开右侧编辑抽屉，修改名称、类型、颜色、说明和画布显示设置。普通标注默认隐藏，打卡、休息、厕所、补给点默认显示；手动显示设置优先，可恢复类型默认。隐藏点仍保留在列表中，其照片与连接线随点隐藏，导出 SVG 遵循相同规则。选择 KML 链接图片或上传本地 PNG/JPEG/WebP。轨迹作为独立 SVG 图层，标题与统计、起终点文字、方向说明、标记和照片位于外层画布；文字、标记与照片可分别自由拖动，文字还可在「画布文字」中填写坐标或恢复默认位置，文字布局随画布保存并支持撤销/重做；连接线跟随更新，拖拽完成后保持选中；外层画布保持固定，标题、统计和方向说明保持独立；轨迹、起终点文字、标记、照片和连接线统一移动与缩放；空白区域或「拖动轨迹」工具移动整组轨迹内容，滚轮和「轨迹缩放」调整整组内容大小，「重置轨迹」恢复路线位置与大小，路线布局随画布保存并支持撤销/重做；也可用方向键和坐标表单调整。支持撤销/重做、缩放、保存可编辑布局；「导出 SVG」导出组合画布，「导出轨迹 SVG」单独导出透明路线图层。最多 100 个标注、20 张照片，照片总量上限 8 MB；照片压缩并嵌入 SVG。画布布局独立保存，原始坐标与文件保留。
- **轨迹视频制作**：顶部切换「素材准备」「脚本策划」「镜头编辑」，默认进入镜头编辑。地图和 3D 沙盘共用工作台及多轨时间轴，显式保存独立工程。脚本策划连接本机 OpenMontage 原生 Backlot，由独立 Desktop Agent 会话依次确认大纲、脚本、分镜。部分镜头进入当前编辑器，按项目与分镜保存，输出真实视频后回填原生素材清单，保留历史版本；不自动启动整片合成或 AI。素材准备保留资源库选用清单，旧浏览器脚本保留备份。详见 [镜头工作台](docs/track-shot-editor.md)、[策划流程](docs/track-video-script.md) 与 [OpenMontage 接入](docs/track-openmontage.md)。
- **轨迹动画录制**：详情点「轨迹动画录制」，先选择文本模型生成 AI 镜头脚本，审阅后采用。支持全景、沿线跟随、点位聚焦镜头；暂停、继续、重播与进度跳转，录制期间固定底图与脚本。输出 WebM 视频，含地图署名、轨迹、进度与镜头字幕。无文件时间/海拔也能播放，动画按路径距离和脚本时长推进。它不请求设备定位，也不采集实时位置。浏览器缺少 MediaRecorder/captureStream 时仍可播放；WebGL 不可用时提供明确提示。
- **后续处理**：轨迹分析将采用 Skill；画布图片 AI 处理保留「逐张优化 / 多图参考生成」方向，具体需求和交互后续梳理，本轮先完善概览与 SVG 标注。

动画脚本通过宿主的 CQAI 账号服务调用所选聊天模型，不在客户端保存或复制密钥；仅在主动点击生成后提交任务。链接图片按需加载，源站不允许跨域读取时可上传本地图片，失败不覆盖已有照片。编辑器报错提示与保持原格式保存，留到后续调整。
## 离线行为

**轨迹线、海拔剖面、基础统计、编辑、SVG 标注、本地视频脚本策划和无底图动画不依赖联网。生成新的 AI 分析、脚本和美化图需要联网；已生成脚本保存在当前浏览器中，可再次审阅并录制。** 解析在导入时完成并随轨迹一起存盘，打开已有轨迹直接使用本地数据。

**底图瓦片和 3D 区域高程**需要联网：二维地图不会请求高程，进入「3D 地图」或「3D 沙盘」后才加载区域 DEM。

| 底图 | 来源 | 离线 |
| --- | --- | --- |
| 矢量（默认） | OpenFreeMap `tiles.openfreemap.org` | 需要联网 |
| 地形 | OpenTopoMap `tile.opentopomap.org` | 需要联网 |
| 卫星 | [Esri World Imagery](https://www.arcgis.com/home/item.html?id=10df2279f9684e4a9f6a7f08febac2a9)，`services.arcgisonline.com` | 需要联网 |
| 无底图 | 无 | 纯色底 + 轨迹线 |
| OpenStreetMap | 公共标准瓦片 `tile.openstreetmap.org` | 仅可见交互地图，沙盘使用地形着色 |
| MapTiler 街道 / 户外 / 卫星 | MapTiler v4 样式，需自有 Key | 需要联网 |
| 3D 高程（默认） | [Mapterhorn](https://mapterhorn.com/data-access/)，Terrarium 编码、512 像素瓦片，最大层级 12 | 需要联网 |
| 3D 高程（可选） | [MapTiler Terrain RGB](https://docs.maptiler.com/schema-raster/terrain-rgb/)，Mapbox 编码、512 像素瓦片，最大层级 14，需 Key | 需要联网 |

底图拉不到时，面板会显示「底图需要联网，当前只显示轨迹线」并自动退回纯色底 —— 失败的只是底图，轨迹线和剖面不受影响。断网时可以手动切到「无底图」，避免在控制台里刷一屏失败请求。

详情页头和地图工具栏的「地图设置」/「设置」可配置底图、高程、MapTiler Key、地形倍率、建筑、沙盘质量及光影；支持连接测试、保存、取消和恢复默认，关闭后保留当前页面与编辑状态。

设置使用版本化 `localStorage`（`cqai-track.map-settings`），兼容旧的 `cqai-track.basemap`，展示、编辑、动画共用配置。Key 默认掩码，只用于浏览器连接服务，不写入轨迹文件、Agent 上下文或应用日志。「地图设置」另提供可选的天地图 API Key，可在天地图控制台申请，保存到当前浏览器；当前仅保存配置，位置反查尚未接入，连接测试仍只检查底图与高程服务。每条轨迹默认进入二维地图；沙盘模式不持久化。地图、沙盘及 WebM 保留实际数据源署名，使用 MapTiler 时附 Logo。

卫星使用 Esri World Imagery 的卫星及航空影像，清晰度与拍摄时间随区域而异；当前在线瓦片接口无需配置 API key。地图与沙盘保留服务提供的影像署名，影像按其来源条款使用，不提供离线批量下载。

沙盘创建独立采样地图，按路线范围外扩 20%、每边至少 150 米，不改变主地图视角。使用所选底图作为贴图；OpenStreetMap 公共标准瓦片不用于离屏采样。底图加载失败时仍可展示地形着色。区域高程失败、加载超过 10 秒或图形上下文丢失时，返回二维地图并显示「重试沙盘」。切换底图会重新生成贴图，切回二维或退出详情会释放沙盘资源。

沙盘轨迹按 DEM 高度贴地，因此文件没有海拔也能显示；导入文件的海拔、统计量和海拔剖面不会被改写。质量默认「标准」：节能 / 标准 / 精细的网格最长边为 96 / 192 / 256，贴图最长边为 1024 / 2048 / 4096 px，并按实际 GPU 能力限制。地形倍率默认 1.25，可调 1–3 倍；高程与路线采用真实米制，分段独立绘制且保留急弯。显示细节仍受高程源分辨率限制。

光影默认太阳方位 315°、高度 35°、主光 2、环境光 0.65、阴影开启；节能档关闭阴影，其他档使用最多 2048 的阴影贴图。调光只更新灯光并重绘，不重新请求高程、加载贴图或重建地形。「恢复默认光影」保留地图源、质量、倍率和视角。

镜头编辑工作台支持地图逐帧 WebM 导出和 3D 沙盘实时录制；画面尺寸与帧率按各自实际能力显示，可取消输出并保留工程。当前未接 MP4、整片混音或实时 GPS。开源方案比较见 [地图录制调研](docs/map-recording-options.md)。

WebGL 拿不到时（某些虚拟机、远程桌面），地图降级为把轨迹投影成 SVG 折线画出来：没有底图也不能拖动，但轨迹的形状还在，海拔剖面照常。

海拔图初始化或数据绘制失败时，只在剖面区域显示提示和「重试剖面」，轨迹详情、统计与操作按钮仍可使用。

**所有底图地址都是 https** —— 应用本身跑在 `http://127.0.0.1`，明文 http 的瓦片会被混合内容策略拦掉。

## 标注照片缓存与大小图

导入或打开轨迹时，插件在后台下载远程照片并缓存源文件，再生成等比例小图（长边最多 1024 px、JPEG 质量 80、不放大小图、按图片方向处理）。地图详情、点位和编组抽屉、列表及 SVG 编辑画布默认加载小图；点击查看大图时读取缓存原图。原图字节、远程来源和标注中的逻辑链接保留，同图重复引用复用缓存，编组、转移及撤销不改用缩略图地址。

本地上传照片也生成小图。图片任务最多并行处理 3 张，单张失败独立显示并可重试，轨迹载入和点位编辑继续可用。下载仅访问公网 HTTP/HTTPS 默认端口，限制大小、超时和重定向；已缓存图片可离线查看，删除整条轨迹时一并移除其缓存。下载到的源图质量以远程地址实际提供的文件为准。

图片缓存本身不执行识图。后续信息提取可复用小图，并按已确认的规则跳过隐藏照片。
## 支持范围

- **格式**：GPX、KML、TCX。
- **不支持的**：FIT（`fit-parser` 有约 10.4k 行，不在范围内）。
- **不做高程纠偏**：上游 wanderer 有一套服务端补高 API（Valhalla），本地没有这个服务，所以 **GPX 里没带 `<ele>` 的轨迹就是没有剖面**，不会凭空造一段出来。面板会直接说「这条轨迹没有海拔数据」。
- KML 里的 `<LineString>` / `<MultiLineString>` / `<Polygon>` / `<MultiPolygon>` 都会读；`Point` 不画。
- TCX 里少于两个 Trackpoint 的 Lap 会被跳过（上游 `@tmcw/togeojson` 的行为）。

## 数据存放在哪

```
<DSH home>/track/<id>/
├── track.json    解析后的坐标 + 列表要用的元数据
├── source.gpx    导入时的原文件，逐字节保留
├── placemark-state.json  标注点编辑、增删、排序和分组的统一状态
├── placemark-photos/     标注点本地图片的副本，按内容哈希命名
├── placemark-thumbnails/ 小图副本，长边最多 1024 px、JPEG 质量 80
├── placemark-photo-assets/ 图片来源、原图与小图关联及处理状态
└── annotations.json     独立 SVG 画布布局和嵌入照片
<DSH home>/track-agent/
├── agent-session.json   公共工作区关联的原生 DSH 会话编号
├── 轨迹/                公共工作区，含 track-context.json 和 AGENTS.md
└── tracks/<trackId>/    每条已保存路线的独立 Agent 工作区
    ├── agent-session.json  当前路线关联的原生 DSH 会话编号
    ├── track-context.json  当前路线与页面的参考快照
    ├── AGENTS.md           Agent 项目说明
```

`<DSH home>` 的解析顺序：显式配置 → `$DSH_HOME` → `~/.dsh`。

解析结果和原文件都存，是因为两者用途不同：断网时要立刻能画（不能等重新解析一个几 MB 的 GPX），而「导出原文件」要的是当初那个文件本身。半写入或手工塞进去的目录在列表里会被跳过，坏一条不会带垮整个列表。

本地服务只监听回环地址，且变更请求（`POST` / `DELETE`）必须带 `x-cqai-track: 1` 头，浏览器里其他页面无法驱动它。轨迹 id 在读写前都要过一遍格式校验，`?id=../../..` 这类越界读取会被当成「轨迹不存在」。

## 安装

**本插件不预装**，以第三方包形式装进 profile：

```sh
dsh plugin --profile desktop add <本插件路径>
```

本地独立项目目录为 `E:\workspace\project\dsh-plugin-track`，可在构建后安装：

```powershell
dsh plugin --profile desktop add E:\workspace\project\dsh-plugin-track
```

之后**重启应用**，侧栏出现「轨迹」入口。

## 构建与测试

在本插件的独立项目目录执行（Node.js `^22.19.0` 或 `>=24.0.0`，Yarn `4.18.0`）：

```powershell
cd E:\workspace\project\dsh-plugin-track
corepack yarn install --immutable
corepack yarn build
corepack yarn typecheck
corepack yarn test
```

`tests/` 覆盖解析、原始文件逐字节导出、正式插件入口启动、服务恢复后的刷新、真实 HTTP 与临时文件存储、海拔缺口、地图/沙盘恢复、高程采样、编辑操作和原子副本保存、SVG 与拖拽照片、带图标注点美化与任务归属、文本 AI 校验、图片队列，镜头案例、录制参数快照，以及动画与录像资源清理。浏览器验收另外验证真实 MapLibre 手势、窄窗口布局和 WebM 捕获；AI 服务验收使用受控响应，不自动消耗真实模型额度。
`lib/client.js` 将 MapLibre GL、chart.js、Three.js、OrbitControls/Line2、Immer 与 Mediabunny 打进同一个 bundle，不依赖客户端白名单之外的运行时模块。
