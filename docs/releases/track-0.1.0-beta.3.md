# Track 0.1.0-beta.3

日期：2026-10-09。延续 npm beta 发行序列。

本版将资源库、AI 图片创作、地图导出和 SVG 样式改进，与主分支已完成的 OpenMontage 策划及共用镜头工作台合并。原工作区的全部修改已保存到提交 `854ffb1`。

## 更新

- 资源库统一管理图片、视频和音频，支持候选、使用关系和视频素材选用。
- AI 图片独立创作页支持主体与效果参考、模板、可取消的提示词优化、任务历史和草稿恢复；保留每条轨迹的 Agent 图片引用与会话。
- 二维地图、3D 地图、3D 沙盘和 SVG 标注可保存 PNG 到资源库；SVG 支持画布比例、尺寸、统一样式与单独覆盖。
- 地图与沙盘支持浮动点位、文字与连线设置、地形遮挡和原始分组位置。
- 保留 OpenMontage 原生策划、地图与沙盘共用镜头工作台、独立分镜工程、录制回填与历史版本。
- 发行包包含对应源码、测试、构建输入和完整第三方许可声明。

## 验证

- 合并后的类型检查通过。
- 全量测试 145 个文件、2731 项通过，使用 `npm test -- --maxWorkers=2` 避免本机并行 worker 启动超时。
- 六处旧测试预期更新为当前画布缩放、标注响应和统一详情容器；生产行为未因这些修复改变。
- AI 服务验证使用受控夹具，未调用计费模型。OpenMontage 使用用户本机的外部项目，完整 Electron/朋友电脑安装不在此次验证范围内。

## 安装与来源

在插件管理中添加 `cqai-dsh-plugin-track@0.1.0-beta.3`，或安装发行页的 tgz，随后重启应用。对应源码与构建步骤见 [BUILDING.md](../../BUILDING.md)，许可及版权说明见 [THIRD_PARTY_NOTICES.md](../../THIRD_PARTY_NOTICES.md)。

本版沿用发布者于 2026-10-08 确认取得的 GeoMotion 分发权限，详见 [分发确认记录](geomotion-distribution-record.md)。
