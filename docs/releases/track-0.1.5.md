# Track 0.1.5

日期：2026-10-10。本版整合此前的轨迹工作台优化，将插件各页面统一为 GeoMotion 风格的紧凑布局，颜色跟随 e宝工坊 Desktop 的当前主题。

## 界面与操作

- 轨迹列表支持搜索、排序及网格/列表切换；统一轨迹概览、线路编辑、标注编辑、地图设置和照片面板的工具栏、间距、边框与选中状态。
- 地图镜头采用左侧图层、中间预览、右侧属性、底部时间轴的连续工作区；增加图层搜索与预览展开，收紧参数面板，滑杆配合数值输入并保留原有小数精度。地图预览根据可用空间调整，窄屏可切换面板。
- SVG 标注、资源库、AI 图片工作区、提示词模板、视频素材准备、策划和沙盘镜头使用一致的面板、按钮与表单密度。资源库保留显示模式与滚动位置，改善窄屏面板切换和对话框关闭后的焦点恢复。
- 所有界面背景、文字、边框、主按钮、选中、悬停及焦点颜色由 DSH 语义主题变量提供；原生选择框、滑杆等控件也使用宿主主题色。布局跟随 GeoMotion，主题切换会同时更新插件界面。
- 轨迹概览的地图截图可保存到当前轨迹资源库，供后续路线图和视频素材使用。

## 标注草稿保存

在标注编辑工作区中，点位、照片、分组、排序及显隐修改先留在当前草稿，撤销/重做也作用于草稿；点击保存后按原版本一次提交。离开编辑或关闭页面时提示处理未保存修改。保存失败或版本冲突时保留当前草稿和历史；结果不确定时先读取核对，避免重复提交或覆盖外部修改。

## 安装

在 e宝工坊 Desktop 插件管理中添加：

```text
cqai-dsh-plugin-track@0.1.5
```

或使用 DSH 命令行：

```sh
dsh plugin --profile desktop add cqai-dsh-plugin-track@0.1.5
```

更新后重启应用，从侧栏「轨迹」进入。本地隔离开发 Beta 如果仍链接当前源码目录，使用本地构建即可，重启后加载新界面。

构建和打包方式见 [BUILDING.md](../../BUILDING.md)，发行归档见 [v0.1.5](https://github.com/g-dxw/dsh-plugin-track/releases/tag/v0.1.5)。此前兼容性发行见 [Track 0.1.4](track-0.1.4.md)。
