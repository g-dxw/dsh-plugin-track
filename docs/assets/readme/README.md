# Track 界面截图

这些截图于 2026-10-09 在实际 e宝工坊 Desktop 中采集，展示 `cqai-dsh-plugin-track@0.1.0-beta.3` 当前工作区的界面。使用与本版插件接口兼容的 DSH 接口包 `0.1.5-rc.1` 的宿主及隔离 Profile；示例线路为仓库已有的「武功山反穿」资料。

截图直接截取应用内容区域，未生成或重绘界面。地图和沙盘保留应用的数据源署名入口；展开该入口可查看实际来源。资源库中的图片为本地导出素材，本次未调用生图模型。

示例统计来自该轨迹文件，不能作为通用路线攻略。采用 DSH 0.2.x 接口包的宿主兼容性说明见[安装章节](../../../README.md#安装)。
