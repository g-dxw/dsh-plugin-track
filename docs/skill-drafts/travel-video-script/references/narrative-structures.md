# 七种叙事结构与选择条件

在选结构、改大纲或解释结构取舍时读取。以下是创作工具，不是对参考影片逐镜头顺序的复刻；示例开场均为拟写文案。

先确认用户已选主目标，再按素材范围、观众需求和可用材料选择主结构，最后考虑辅助结构。主目标未明确时先询问，不从结构示例反推用户目标。不要因为喜欢某种套路，补造已发生事件。

下列“适用条件”在当前素材剪辑时用于判断材料是否成立；在扩展模式的拍摄策划中，也可作为需要检索、取得或补拍的目标。允许根据路线理解和网上资料规划完整叙事，不要求所需画面已在本地。拟拍过程、人物采访和潜在体验标为提案，不预写成用户亲历。

## 1. 行程交付型

**适用条件：**观众需要可执行安排，资料足以说明路线、交通、时间、住宿或费用及关键限制。

**推进：**值得去的理由 → 适用条件 → 路线总览 → 分段安排与体验 → 代价和取舍 → 完整方案。

**核心交付：**不仅知道去了哪里，也知道为什么这样安排，以及时间不足时如何调整。

**示例开场：**“只有两天，又想留出真正走路的时间。这次把交通、徒步和住宿连起来，看这个周末怎样安排才合适。”

**避开：**机械按天报行程，只说“做了什么”，不给安排理由；关键信息缺失却宣称完整攻略。

## 2. 目标推进型

**适用条件：**有真实目标、行动和阶段进展；如有变化或选择，能够从素材与记录中确认。

**推进：**目标与条件 → 行动 → 进展 → 真实变化 → 选择 → 完成或调整 → 复盘。没有变化时可简化，不强制插入挫折。

**核心交付：**观众知道当前位置、目标进度、行动原因和结果。

**示例开场：**“今天计划走到山脊观景点。我会记录最耗体力的路段，看看按这样的节奏，计划能否完成。”

**避开：**把普通行程包装成生死挑战，或只重复“很累、继续加油”，却没有具体过程。

## 3. 预期验证型

**适用条件：**有明确说法、合理判断标准，以及可支持或限制结论的观察证据。

**推进：**提出说法 → 说明标准 → 实地观察 → 符合与不符合的证据 → 有条件的结论。

**核心交付：**判断对什么人、什么条件成立，并指出尚未验证的范围。拍摄后整理也可采用，但不得虚构出发前的验证计划。

**示例开场：**“这条线常被推荐给新手。我们这次关注路面、爬升和退出条件，看看这个推荐在什么情况下成立。”

**避开：**先写好反转结论，再挑画面证明；临时改变标准；用一次体验代表所有季节和所有人。

## 4. 方案取舍型

**适用条件：**存在真实备选方案，能够比较时间、预算、体力、交通或体验代价。

**推进：**约束 → 备选方案 → 各自代价 → 实际选择与体验 → 分人群建议。

**核心交付：**让观众根据自己的条件选择，而不是只接受作者的偏好。

**示例开场：**“同样三天假期，多去一站和少换一次住宿，会把时间花在不同地方。这次把两种走法的代价说清楚。”

**避开：**隐去所选方案的缺点；把没有实际走过的备选写成亲测结果。未实测方案注明资料来源与估算。

## 5. 沉浸同行型

**适用条件：**连续的行走、环境或日常过程素材足以建立空间推进；声音与留白能够支持体验。

**推进：**进入环境 → 开始行走 → 地貌与真实身体状态变化 → 停留或住宿 → 关键体验 → 离开与回落。按真实旅程选择节点，不强制全套出现。

**核心交付：**观众感觉在同行，知道环境如何连起来；不要求每段解释攻略信息。

**示例开场处理：**脚步和环境声带观众进入树林，少量文字交代地点与日期，随后以空间变化推进。若没有原始现场声，标明声音设计计划。

**避开：**漂亮素材互不相连；密集字幕打断体验；为了故事张力虚构独行感受或身体状态。

与攻略结合时，在必要节点给简洁信息，完整安排放配套总结，不占满每个安静画面。

## 6. 寻找与人物型

**适用条件：**确有相关人物、交流或行动素材，人物与线索改变了旅程选择、判断或理解。

**推进：**带着问题出发 → 寻找线索 → 遇见人物 → 理解变化 → 找到答案或保留未解问题 → 回扣开头。

**核心交付：**地点和人物参与问题的展开，保留他们真实的经历与观点。

**示例开场：**“沿途几次交谈之后，我开始关心：现在还有谁在使用这段古道？”仅在已有相关交流材料时使用这种回顾表述。

**避开：**编造访谈；把当地人当作预设升华的符号；让一位受访者代表整个地方；采访内容与后续故事脱节。

## 7. 问题清单型

**适用条件：**观众有若干具体疑问，材料能逐项回答；不需要强故事才能交付价值。

**推进：**最重要问题 → 按决策顺序回答 → 对应现场或可靠资料证据 → 行动清单。

**核心交付：**每解决一项，观众就更接近能安排出行。可按出发前、到达、途中、结束组织，但优先遵从实际决策顺序。

**示例开场：**“第一次走这条线，先确认三个问题：怎么到起点，途中怎样提前结束，走完如何返程。”

**避开：**随机堆注意事项；只给结论不给依据；把普通提醒都包装成“千万别做”。

## 素材不足时的结构调整

以下表格用于“只用当前轨迹素材”时收束表达。扩展模式可检索相关资料、补充路线背景并设计完整故事或攻略，将缺少的画面、采访与现场记录列为待取得或待拍；两种模式都不把未发生事件说成实测。

| 现有材料 | 可以先做 | 不能直接承诺 |
| --- | --- | --- |
| 只有轨迹和少量照片 | 路线空间介绍、待核实问题清单、拍摄策划 | 实测完整攻略、新手适合、真实人物故事 |
| 有真实行程记录，费用或交通已过时 | 当次旅程回顾，并列出当前待核验信息 | 直接可用的当前费用与班次方案 |
| 有风景素材，无连续过程或现场声 | 风景短片草稿、补拍与声音设计计划 | 已具备连续同行体验或原始环境录音 |
| 有一次体验，缺少其他条件样本 | 有边界的体验结论、待验证范围 | 所有季节、人群和天气都适用的评价 |
