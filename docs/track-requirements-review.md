## 2. 当前设计的问题在哪里

以下是对当前源码的梳理，不是桌面界面的运行验收。

| 当前情况 | 用户理解上的问题 | 重梳方向 |
| --- | --- | --- |
| 详情同时挂载「轨迹分析」和「AI 路线分析」，后者自带模型选择与输入表单 | 基础数据检查、AI 建议、地图查看分散在不同区块；分析更像一个页面功能 | 记录现状，轨迹分析 Skill 的方案后续再梳理 |
| 当前编辑器提供地图操作、绘制、选点、分段与合并等工具 | 用户已明确现有编辑器可以继续使用 | 以现有编辑器为基础，具体交互改进留到后续 |
| 当前编辑保存统一生成 GPX 副本 | 与「编辑后仍保持原格式」的要求存在差异 | 后续完善原格式保存，不把统一 GPX 作为最终需求 |
| 编辑器的报错提示仍需完善 | 用户指出报错处理还不够恰当 | 记录后续改进，具体场景与提示文案以后再梳理 |
| 当前标注页先展示地图与表单，再展示 SVG 画布及 AI 表单 | 画布中的标注操作没有成为主要流程 | 将 SVG 画布作为标注主界面，在画布添加点位、展示照片与说明 |
| 现有 SVG 已有点位和图片拖拽、连接线，默认照片排在路线区域下方 | 与参考图中照片围绕整条轨迹分布的排版存在差异 | 沿用现有 SVG 基础，围绕整张画布组织点位与照片布局 |
| KML 转换结果随后只提取线路；`Point` 点位及其描述、图片链接没有进入轨迹数据 | 文件明明带地点与照片，界面却需要用户重新添加 | 导入时保留 KML 点位与图片引用；已有导入记录建议从保留的原文件恢复 |
| 当前标注模型绑定轨迹点序号，每个标注只存一张本地图片；画布拖动点位会吸附到轨迹采样点 | 画布新增点位、图片来源与拖动规则仍需完善 | 按画布标注的需求细化，不直接认定必须吸附或必须自由移动 |

现有功能已经存在，不代表本次全部保留或删除。需求确认时逐项决定，已有数据的处理另行列清。

## 3. 功能边界建议

**编辑与新建沿用现有编辑器的方向已确认；其余分工建议仍待确认。**

| 用户任务 | 建议由谁承接 | 主要结果 |
| --- | --- | --- |
| 导入、管理、查看轨迹 | 轨迹插件界面 | 地图、剖面、基础统计与文件导出 |
| 编辑已有轨迹 | 现有地图编辑器，加载当前轨迹 | 编辑结果；原格式保存与报错提示后续完善 |
| 新建路线 | 与编辑相近的地图编辑器，从空白草稿开始 | 新路线草稿；保存格式与细节后续调整 |
| 查看 KML 自带地点与链接图片 | 轨迹插件的地图与图片面板 | 点位信息、图片预览与图片选择 |
| 制作轨迹标注图 | SVG 画布编辑界面 | 轨迹轮廓、点位、照片卡片、文字和连接线组成的路线图 |

距离、爬升、海拔剖面等确定性数据建议继续由程序计算和展示。轨迹分析 Skill 与 AI 图片处理的功能边界后续另行确认。

### 入口结构草案

```text
轨迹库
├─ 导入轨迹
├─ 新建路线                 进入编辑器，从空白草稿开始
└─ 打开已有轨迹
   ├─ 概览                  地图、右侧标注点列表、剖面、基础统计
   │  └─ 地点与图片         从右侧列表或地图选中点位，查看说明与图片
   ├─ 编辑当前轨迹          进入现有编辑器，加载当前轨迹
   ├─ 轨迹标注              轨迹转 SVG 画布，添加 / 拖动点位，展示照片与说明
   └─ 其他操作              导出等；动画的位置和是否保留待定
```

「新建路线」与「编辑当前轨迹」分别提供入口，编辑器结构和工具交互保持相近。

### 右侧标注点列表的交互建议

- 每项展示缩略图、编号、非空名称、图片数量、点位海拔和时间；没有图片的点位也保留在列表中，缺少海拔或时间时隐藏相应内容。
- 默认按标注点自身的有效时间升序展示；同一时间保持原顺序，缺失或无效时间的点位放在后面并保持相对顺序。起点、终点名称不强制改变时间顺序。
- 概览只展示保存后的点位顺序、位置和照片关联；排序、迁移照片与修正位置的入口统一放在「编辑当前轨迹 → 标注点编辑」，概览中不提供处理操作。三处使用同一编号与点位 ID。
- 已保存为隐藏的标注点只从地图移除，右侧列表淡色保留，海拔剖面及点位编号不因隐藏改变；隐藏和编辑操作仍在标注点编辑中完成。
- 地图标记缩小为 24 px 编号圆点，保留 32 px 点击范围。
- 点击地图标记或列表项，地图定位并高亮该点。详情展示照片，宽高按照片原始比例及地图可用空间调整；时间、海拔、坐标、非空标题与说明浮在照片底部，以渐变底衬提高可读性，可关闭后再次打开。没有图片或图片加载失败时恢复普通文字布局。
- 没有标题或说明时隐藏对应内容，不显示「标注点 74」「暂无说明」等占位文字；照片点位仍保留在地图与列表中。
- 点击照片或照片底部浮层中的「查看大图」打开大图查看器；关闭或按 Escape 后返回同一个点位详情。
- 点击地图标注点，列表滚动到对应项并高亮；地图与列表保持同一个选中点位。
- 海拔剖面也展示同一批标注点，按最近轨迹位置对应沿途里程，编号与地图、列表一致。三处共用选中状态，点击剖面点位打开地图详情；密集点合并为可展开选择的组，缩放和平移后标记跟随曲线。
- 列表较长时独立滚动，地图保持可见。列表缩略图延迟加载，点位详情照片在选中后加载；单张失败可重试。
- 无标注点时显示「这条轨迹没有标注点」，不影响地图和剖面查看。

窄窗口建议将辅助面板收成抽屉或上下布局；地图、当前任务和主要按钮仍可使用。

## 5. 编辑已有轨迹：沿用当前编辑器

### P3：编辑当前轨迹（现有界面作为基础）

已确认沿用当前编辑器结构及地图、绘制、选点、分段、合并等工具交互。本轮不重新制定编辑器布局或操作流程，具体调整留到后续。

### 已记录的后续改进

- **报错提示：** 当前提示还不够恰当；具体失败场景、文案和处理方式后续再梳理。
- **保持原格式：** 编辑后应保持原轨迹格式，例如 KML → KML、GPX → GPX，具体实现后续调整。

当前实现统一保存为新的 GPX 副本，这是现状说明，不是最终保存格式要求。原格式保存是否涉及副本、覆盖及点位信息保留等细节，留到后续编辑器调整时确定。

### 标注点编辑 · 本轮新增

- 打开已有轨迹的「编辑当前轨迹」时，默认进入「标注点编辑」。标签按「标注点编辑 / 线路编辑」排列；线路编辑继续使用现有工具，切换时保留线路草稿。左右方向键按可见顺序切换并循环，Home 回到标注点编辑，End 切到线路编辑。新建路线仍只提供线路编辑。
- 标注点默认按时间排列，支持拖拽手动排序，用于修正图片时间缺失、二次编辑等情况；提供上下移按钮与键盘操作，也可恢复时间排序。
- 照片可单独拖到另一个已有标注点，或通过「移动到点位」选择目标；迁移关联时保留两个点位的名称、时间和位置。
- 地图标记可拖动，或用 Alt + 方向键修正位置，松开后吸附到实际连续轨迹段；重叠经过需确认具体候选，坐标、时间和海拔按稳定位置重新计算，未移动的原有点保持原始信息，海拔图与地图同步。
- 排序、位置与照片关联自动保存到当前轨迹，再次打开继续使用；保存中锁定编辑和返回操作，失败恢复原状态并提示。独立保存调整记录，不修改导入的原始文件和轨迹线路。
- 返回概览后仅查看已保存的结果，概览中不再出现拖拽与处理入口；排序与点位编辑的报错、重试入口也仅在编辑器中显示。

### 地图标注点详情与编辑抽屉 · 本轮确认

- 标注点编辑中的地图详情，在「查看大图」旁增加「编辑」入口；照片查看与点位编辑分别进入各自界面。
- 右侧列表为每个点位提供独立编辑图标与隐藏 / 显示图标，点击图标执行相应操作，点击行仍选中点位并查看详情。
- 隐藏只控制地图是否展示该标注点，不删除点位、图片或时间等信息，也不改变列表及海拔剖面的编号。隐藏项在列表中淡色显示，仍可打开编辑抽屉，并可恢复地图显示。
- 从地图详情或列表编辑图标打开同一个点位抽屉。抽屉提供名称、描述、关联图片和类型编辑，使用稳定点位 ID 保存；不修改轨迹线路或导入的原始文件。
- 图片可从本轨迹已有图片中选择，可添加或修改 HTTP(S) 图片链接，也可选择本地文件，允许混合多张图片及移除关联。本地文件复制到当前轨迹的图片目录，点位保存后刷新或重开仍可查看。
- 类型提供「风景点、休息点、补给点、厕所、打卡点、起点、终点」七个独立复选框，可同时选中多个预设。自定义标签通过输入后点击「添加标签」或按 Enter 添加，可连续添加多个，Enter 只添加标签，不提交整个抽屉；每个自定义标签均可单独移除。预设与多个自定义标签同时保留，取消全部勾选并移除自定义标签后保存为未分类。
- 新界面将类型保存为标签数组，空数组表示未分类；旧数据中的单个类型字符串仍可读取、初始化和展示，继续编辑后按数组保存。列表和地图详情展示全部标签，不覆盖其中任意一项。地图标注点类型与 SVG 画布已有类型分别处理。
- 保存成功后地图、列表和海拔剖面共用更新后的点位信息；保存中锁定相关编辑、标签切换和返回，失败保留或恢复原状态并清楚提示。

### 标注点编辑的撤销 / 重做 · 本轮确认

- 点位页头部提供「撤销 / 重做」按钮和快捷键提示，仅作用于本次编辑会话。支持点位排序、恢复时间排序、位置修正、照片移动、隐藏 / 显示，以及名称、描述、图片和类型修改。
- 一次拖动、一次排序或显隐操作各记录一步；照片移动同时恢复源点与目标点的关联。抽屉中的多项修改在点击「保存点位」并成功保存后合并为一步，逐个字段输入不推进点位历史。
- Ctrl / Cmd + Z 撤销；Ctrl / Cmd + Shift + Z 或 Ctrl + Y 重做。撤销和重做也将对应结果保存到当前轨迹，地图、列表和剖面同步更新；新修改成功保存后清空原重做分支。
- 输入框、文本框、选择框和可编辑文字区域保留原生文字撤销；抽屉或大图查看器打开时不能撤回背后的点位操作。拖拽、读取和保存期间禁用点位撤销 / 重做，保存失败不推进历史，撤销 / 重做失败保留可重试的步骤。
- 点位与线路分别保留自己的历史，切换「标注点编辑 / 线路编辑」后可继续各自的撤销 / 重做，不互相改变另一类数据。退出编辑再进入时，点位历史从空开始，已成功保存的点位结果继续保留。
- 概览仅展示已保存结果，不提供撤销 / 重做按钮或点位编辑快捷键。

### 标记点分组 · 本轮确认

- 「标注点编辑」中，未分组点和已展开的组内子点常驻勾选框，不再提供「选择打组」或工具栏「打组」按钮。选择至少两个未分组点后右键，在菜单点击「打组（N）」直接保存为组，默认名称和封面随后可用组编辑抽屉修改；失败保留原选择并可重试，只有保存成功才记录一步撤销。每个成员只能属于一个组，不支持嵌套。
- 普通点位行点击单选并查看详情；勾选框或 Ctrl / Cmd 点击可逐项多选，Shift 点击按当前可见点位顺序批量选择范围内的独立点及已展开组内子点，跳过折叠组成员，保留范围外的勾选。Shift 点击已勾选点批量取消对应范围，连续 Shift 沿用最近一次普通选择的起点。键盘聚焦点位行时，Shift + Enter / 空格进行范围选择，Shift + F10 或菜单键打开右键菜单；菜单可用方向键选择操作，Escape 或点击外部取消。取消选择、切换轨迹或建组成功后清空选择及起点；多选过程不保存数据，概览不提供勾选或右键编辑。
- 抽屉编辑组名、描述、默认图片与组自身显隐；成员区域只展示当前组内点位，采用缩略图、原编号、名称、类型、海拔、时间和隐藏状态的列表卡片，行尾图标可移出成员，移出在保存后生效，不展示外部点位候选。已有组可缩减为一个成员并继续保留，不允许保存空组；解散组作为明确的独立操作提供。
- 成员按当前全体点位顺序展示。类型自动汇总全体成员的去重标签，包含隐藏成员，组自身不另设类型编辑。默认图片可从全部成员图片中选择，隐藏成员的候选图标明已隐藏；隐藏子点只使其退出展示轮播，不更改已保存封面，修改组名或描述时继续保留该引用。封面成员移出组或对应图片移除后，才改用首张有效成员图片；无图片时仍能保存且不设置封面。
- 新组的初始坐标取最终选择封面的来源点，包含隐藏子点；没有图片时取当前顺序的第一个成员。已有组更换封面不移动组位置。拖动组标记时吸附到轨迹，只修改组坐标；成员坐标、照片关联及轨迹原始数据保留。
- 列表默认折叠新组，展开 / 收起移至组行右侧操作区域，使用较小的无边框箭头图标，保留键盘焦点及展开状态提示。组编号为 G1、G2 等，按组中最早成员在当前点位顺序的出现先后排列。子点仍使用全体点位数组的编号，例如 G1 含第 1、3 点时，独立第 2 点继续显示 2；地图、列表和海拔图保持对应关系。
- 点击地图或海拔图中的子点，展开对应组并选中该子点；选中组时，海拔图对应当前详情展示图片的来源点，封面隐藏时暂用可展示图片，没有可展示图片时对应首个可见成员。分组及点位信息未读完时先显示读取状态；读取失败提供重试，避免把未读分组的子点当作独立点展示。
- 拖动独立点的行或拖动手柄到组行中间（封面 / 文字区域）或已展开子点行中间，出现「松开加入分组」提示；松开后直接加入该组并展开，坐标、默认封面、组显隐及已有成员引用保留，只保存组关系。已有组成员不能直接跨组拖入，先在抽屉移出并保存；照片继续拖到具体子点，不将照片拖入解释为整个成员加入。
- 拖动手柄使用指针捕获，鼠标与触摸采用同一操作；整行原生拖放继续保留。小幅点击、取消、失焦和切换轨迹不保存；松手时按实际落点判断加入或排序，释放捕获不重复提交。拖动期间暂停多选、右键建组、显隐、其他排序及照片移动按钮，完成后恢复。
- 列表顶层拖动把整组或独立点视为一行，移动后将完整成员 ID 展平成全体点位顺序保存；组行上下边缘继续用于排序，并用插入线与中间加入操作区分。组内排序只替换该组在全体顺序中占据的位置，其他点保持位置；不能通过拖拽把子点移到组外或跨到另一组。
- 隐藏组仅控制整个组的地图展示，保留每个子点自身的显隐状态；隐藏或全部子点隐藏时，组在列表中仍可展开和编辑。解散恢复成员独立展示，保留其 ID、信息、坐标、图片与显隐。创建、组信息保存、组位置、组显隐、解散及排序均纳入现有会话撤销 / 重做；保存失败恢复原结果并保留可重试草稿。
- 概览可展开分组、选择组或子点和查看图片；创建、修改、拖动、排序、显隐与解散操作集中在编辑页。
- 二维地图和无 WebGL 的 SVG 地图降级只展示独立点与蓝色叠层组点，组点显示 G 编号及成员数量；海拔图继续展示每个子点的实际轨迹位置和原编号。独立 SVG 标注画布、3D 沙盘和动画沿用现状。
- 组详情一次显示一张图片，按子点当前顺序和各自图片顺序排列，提供左右按钮、方向键与计数，无自动播放；大图沿用同一轮播。新打开默认使用所选封面，失效或隐藏时回退到首张可展示图片，加载失败可重试并继续切换。没有图片或隐藏的子点仍能查看自身信息，隐藏照片不展示。
- 图片底部浮层保留组名、描述、类型和当前子点的名称、描述、时间、海拔及坐标；切换图片同步选中其来源子点。隐藏子点的图片退出轮播，全部子点隐藏时组点消失；类型继续汇总隐藏成员。保存新封面后选中组时，可展示的封面用于详情和海拔图；封面隐藏时两者使用同一临时展示来源，已保存封面引用保留。
- 分组仍使用独立 `PlacemarkGroup` 模型，封面保存子点 ID 与图片 URL；与新增、删除、点位编辑及排序一起写入统一 `placemark-state.json`。旧分组接口继续转接该字段，旧三个保存文件在首次成功保存前作为迁移来源；读取失败锁定编辑并提供重试。尚未恢复的成员 ID 和封面引用只读保留，修改元信息不会静默移除。


### 新增与删除标注点 · v1.5 已确认

- 「新增标注」进入地图定位模式：点击地图后吸附到轨迹并打开抽屉，填写名称、描述、图片和多选类型；位置、时间与海拔只读。可携带草稿返回地图重新定位，保存才创建，取消不改变数据。二维地图与 SVG 降级均支持点击定位，并提供「使用地图中心位置」供键盘定位。
- 保存后新点使用稳定的 local-UUID，地图拖动和 Alt + 方向键位置调整与既有点一致。每次移动都重新计算坐标、海拔和时间；原有点未移动时保留原值。稳定轨迹位置保存起止采样点索引与线段比例，地图、时间、海拔及剖面均使用这份引用，往返 / 回环不会回到首次经过的位置。
- 保留 GPX / KML / TCX 原始连续分段，禁止吸附到段间连接线。新导入保存分段索引；旧轨迹从原文件恢复并核对坐标。恢复失败仅锁定新增和移动，原有点仍可查看、编辑信息及删除。二维地图与 SVG 降级使用相同边界，无效 GPS 点也断开线路；SVG 对跨日期变更线共用展开经度坐标系绘制、点击和拖动，反算后归一化经度。
- 最近距离加 5 米范围内按距离局部极小值提供经过候选，显示沿途里程、时间和海拔。共同顶点同一位置合并；去程、返程即使相邻仍分别保留。候选确认后才创建草稿或保存移动，取消恢复原位置。
- 海拔按所在线段两端有效值插值，恰在端点取该端值；必要数据缺失时留空。时间先用同一连续路段前后最近有效轨迹采样时间，按沿途距离插值，倒序区间不用。
- 无可靠轨迹时间时，使用导入文件中固定的原始标注位置和时间作参照：距路线不超过 50 米、经过唯一、同一路段前后时间递增，同位置冲突排除；没有前后参照则留空，不向首尾外推。估算值显示「估算」，来源保存为轨迹计算、估算或未知。新增点、计算结果、后续编辑，以及显隐、删除、移动均不改变这份基线。
- 编辑抽屉提供「删除标注点」，多选右键提供「删除所选标注点」。确认显示名称或编号及数量，取消保留当前选择和抽屉草稿；失败保留草稿并允许重试。展开的组内子点支持选择删除；右键打组仍要求至少两个且全部未分组，不提供直接删除整组入口。
- 删除点同时从地图、列表、海拔图和照片轮播移除，清理编辑、排序及成员引用。图片文件及原始轨迹文件保留；删除封面所属点后回退到剩余可见成员第一张照片，无图则清空封面；组坐标不变，一个成员仍保留组，空组移除。允许删除全部标注，轨迹线与统计保持原样。
- 新增、移动及一次单点 / 批量删除分别记为一步历史；删除撤销完整恢复信息、图片、顺序、组关系及封面。无手动排序时新点按计算时间参与排序，已有手动排序时追加到末尾，可继续拖动。
- 统一 placemark-state.json 保存新增点、原始点删除记录、编辑、顺序、组、恢复后的分段和固定原始时间参照。GET / POST /api/cqai-track/placemark-state 整份校验并原子保存；递增 revision 拒绝过期覆盖，版本不进入撤销内容。
- 新文件缺失时读取旧编辑 / 排序 / 分组三个文件，首次成功保存切换到统一状态；旧接口转接对应字段。新状态损坏时锁定编辑、提供重试，不能退回旧数据覆盖。保存失败恢复原状态且不推进历史，响应不确定时重新读取核实；版本冲突保留草稿、读取已保存状态并提示重试。
- 概览读取新增和删除后的保存结果，继续只读；独立 SVG 标注画布、3D 沙盘、动画及原文件导出沿用现状。


### 标记点链接与本地图片 · v1.6 已确认

- 新增及编辑标注点的同一抽屉同时提供「添加图片链接」和「添加本地图片」，可选择多个本地文件；两种来源合计最多 30 张，可混合保存。

- 文件导入成功只加入当前抽屉草稿，保存点位才保存图片关联；取消沿用未保存修改确认。本地项展示缩略图及「本地图片」来源，支持移除，不把内部地址作为可编辑链接展示；远程项保留链接编辑。
- 本地原图按内容摘要去重，复制到当前轨迹的 placemark-photos 目录，不依赖电脑原路径、临时 blob URL 或把图片大段嵌入点位 JSON。现有链接保持不变。
- POST /api/cqai-track/placemark-photos?id=轨迹ID 接收有界图片字节并返回稳定引用；GET /api/cqai-track/placemark-photo?id=轨迹ID&photo=图片ID 读取。仅接受图片格式并检查真实内容和大小，不读取任意本地文件路径。
- 点位状态、图片迁移、历史、列表缩略图、地图详情、大图、组封面及轮播统一使用稳定引用，刷新和重新进入后继续有效。删除点位或撤销关联保留已导入图片，以便恢复；删除整条轨迹时清理该轨迹自己的图片目录。导入文件原件及电脑上的原图片保持原样。
