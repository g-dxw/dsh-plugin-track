# 轨迹视频脚本

在轨迹详情点击「轨迹视频制作」，先进入[镜头案例库](track-shot-cases.md)试镜头；具体内容确定后点击「进入脚本策划（后续使用）」。这是视频制作的脚本准备模块：先分析轨迹，再确认内容镜头，最后逐镜编辑和确认。

## 操作流程

1. 进入后读取当前路线、已保存的点位编辑及 SVG 标注，在本地重新计算信息。查看摘要、每个候选的事实、依据、画面建议和缺失资料。
2. 勾选资料完整的内容镜头，填写影片目标，点击「确认选题，建立脚本草稿」。可只选择一个镜头，最多 24 个。
3. 逐镜编辑标题、时长、画面、相机运镜、旁白、屏幕文字及素材要求；调整顺序或删除镜头，支持撤销和重做。点击「确认当前镜头」确认这版计划，修改该镜头会重新变为待确认。
4. 可选展开 AI 建议区，选择宿主 CQAI 文本模型并主动生成。结果先完整展示，只有点击「采用 AI 建议」才替换人工草稿；所有镜头重新等待确认，也可撤销。
5. 导出 JSON 供后续片段制作模块读取，或导出 Markdown 用于审阅。未确认镜头仍会明确保留待确认状态。

返回选题后重新建立草稿会再次显示替换提示。原稿不会因重新分析或 AI 返回自动覆盖。草稿保存在当前浏览器的 `cqai-track.video-script.<track.id>`，建议用导出文件备份。

## 能拆出的内容

| 内容镜头 | 分析依据 | 边界 |
| --- | --- | --- |
| 路线总览、路线推进、起终点 | 连续轨迹坐标、分段、重新计算的距离 | 不跨断点连接；起点不自动视为集合点 |
| 海拔剖面、最高采样点 | 文件中的有效海拔 | 最高采样点不代表已核实的山顶或垭口 |
| 连续上升、下降采样段 | 同一段内至少三个有效样本、净高度变化至少 20 米 | 保守候选，不据此判断技术难度 |
| 已保存独立点位、SVG 标注 | 有效坐标、名称、分类、说明、关联照片数量 | 隐藏点不采用；独立坐标不吸附到轨迹；用户说明标明未外部核验 |
| 时间采样停留 | 同一连续段内、30 米内至少三个真实采样，持续至少 5 分钟 | 必须确认实际用途，不能直接说成休息或补给设施 |
| 地形与路线关系、周边山峰、集合准备 | 当前轨迹通常缺少区域高程、真实峰位或集合安排 | 显示待补清单，资料不足的候选不能直接采用 |

单镜建议时长为 3–120 秒，总时长上限 1800 秒；影片秒数与 GPS 记录时间独立。候选最多显示 48 个，超出时提示缩小范围。若要介绍已确认的周边地点，可先在路线编辑中保存独立点位及说明，再返回重新分析；山峰名称、海拔、集合时间仍需提供可靠依据。

## 当前实现范围

地图用于核对位置，可按需查看现有二维/3D 地图；这里没有录制运镜、生成配音或合成片段。脚本尚未直接接入「轨迹动画录制」的旧格式，JSON 保存完整镜头目标和计划，留给后续镜头库与片段制作使用。现有动画录制继续使用原流程。

本地分析、人工脚本编辑及无底图定位可离线工作。AI 请求只包含有界摘要、选中镜头的事实与文字说明、目标坐标及补充要求，不包含完整轨迹、源文件或照片。AI 账号和密钥由宿主处理；模型不可用时仍可手工制作。

草稿恢复会核对路线编号、当前轨迹和点位指纹、镜头类型及目标位置。数据变化或缓存损坏时保留原缓存并提示重新确认选题，不自动覆盖旧稿。删除路线成功时清理该路线的脚本缓存，其他路线保留。
