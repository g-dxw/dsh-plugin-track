# 攻略视频镜头案例

轨迹详情 →「轨迹视频制作」默认打开镜头案例库。用当前轨迹作为演示数据，先观察、调整和录制固定镜头；这些案例不代表已采用进某个成片脚本。

## 三个层次

- **内容信息**：起点、终点、距离、上升高度、记录时间跨度，及需要用户补充的难度、故事、景点资料。
- **叙事方式**：先起点再终点和全貌；先故事文字再引出地点；先局部风景再交代位置和全貌。
- **基础镜头**：整线描画、定点展示、全景推近一点、从点拉远到全景、沿线跟随、从一段局部展开到全貌。

叙事方式组合多个基础镜头。旁白与信息展示不等同于相机运镜；地图镜头也不决定整部攻略视频的内容。

| 基础镜头 | 镜头输入 | 可承担的讲述作用 |
| --- | --- | --- |
| 整线描画 | 整体路线、时长 | 介绍走法、交代路线全貌 |
| 定点展示 | 坐标、名称、示例文字 | 介绍起终点、景点或已核实集合地点 |
| 全景推近点 | 路线全景、目标点、推近幅度 | 回答这个位置在哪里 |
| 点拉远到全景 | 目标点、路线全景 | 从一个位置引出整条线路 |
| 沿线跟随 | 连续路线、时长 | 展示行进过程和方向 |
| 某段展开到整线 | 局部起止点、整体路线 | 先介绍一段，再交代它在全程的位置 |

路线介绍组合采用起点、终点、全景信息三个阶段；故事开场采用示例文字、地点和路线三个阶段；局部开场采用选定点位、地点交代和全貌三个阶段。故事与风景素材的剪辑可以在以后叠加这些镜头。

## 先试镜头

1. 选择「基础地图镜头」或「叙事组合案例」。页面显示该案例的镜头顺序和输入要求。
2. 选择轨迹点或已保存的可见独立点位；局部案例指定同一连续轨迹段内的起止点。调整秒数、推近幅度、方向、俯视角和示例文字。
3. 查看起、中、末画面，播放、暂停或拖动进度。参数变化后回到起始画面，立即查看新效果，无需确认采用脚本。
4. 点击录制生成 WebM 案例。录制从起始帧开始，并在末帧真实绘制后结束；期间锁定参数和底图。结束时短暂保持末帧，录像总长与设定的动作时长可能略有差异。完成后可直接观看或下载。
5. 可导出当前案例配置 JSON；已录制视频也可导出其独立参数快照，修改预览不改变已录视频。以后要策划具体攻略内容，再进入「脚本策划」。

旧轨迹若尚未恢复原文件中的分段信息，可先预览；核对完成前暂不能录制或导出配置。读取失败可在本页重试。

路线介绍案例呈现起点、终点和整体信息。距离和上升来自轨迹重新计算，时间仅作为记录跨度；无法由轨迹推断真实攻略难度。故事和风景引入使用示例文字与位置，实际旁白、故事资料、实拍风景和声音需另行提供。

## 演示边界

本轮案例采用 MapLibre 地图相机，不加载区域 DEM。调整俯视角展示的是地图斜视，不表示已经生成真实山体起伏。真实 3D 沙盘仍在路线地图中按需查看，沙盘镜头录制后续接入。

无底图也可试镜头；在线底图需要联网。录制画面保留实际底图来源署名，不能使用浏览器录制能力时明确提示。参数修改不会改变原轨迹或已有成片脚本；案例录制没有配音、实际风景素材生成或成片合成。

旧脚本策划说明见 [轨迹视频脚本](track-video-script.md)。
