# 轨迹 Agent 对话布局设计

## 工作区与当前范围

工作区固定为「轨迹」，不绑定单条线路。Agent 初次打开时显示轨迹库数量、当前页面、当前线路和完整轨迹编号；列表页显示「未选择线路」。切换线路只更新这个范围，同一个原生会话和输入草稿继续保留。新建路线显示「未保存路线」，暂不把未保存内容提供给 Agent。旧的逐线路工作区和历史会话保留，不做删除。

```text
┌──────────────────────────────────┐
│ Agent · 轨迹助手           [关闭] │
│ 工作区：轨迹（固定）             │
│ 轨迹库：12 条轨迹                │
│ 当前页面：轨迹列表               │
│ 当前线路：未选择线路             │
│ 轨迹编号：未选择线路             │
├──────────────────────────────────┤
│ 原生 DSH 对话                    │
│ ……                               │
│ [描述你的需求……]          [发送] │
└──────────────────────────────────┘
```

轨迹编号使用完整的稳定 `track.id`，不使用列表序号；未选择线路时不提供编号，新建未保存路线显示「尚未保存」。参考快照中的 `current.trackId` 与该编号一致。

`track-context.json` 随当前页面、线路及轨迹库数量变化更新参考快照，`AGENTS.md` 提示 Agent 在回答当前范围前读取它。它没有实现每条消息的强制上下文注入，也未接入轨迹/标注/分组的编辑工具；后续工具调用应以明确的当前范围和成功结果为依据。


状态：设计草案。本文只约定布局和交互，没有修改应用代码。

推荐：Agent 放在 DSH 导航与轨迹地图之间，由 DSH Desktop 壳托管，内部复用官方 Conversation。宽窗口从左到右为“DSH 导航 → 左侧 Agent → 地图 → 点位列表”。轨迹入口采用纯对话模式，输入框始终可见。宽度不足时先折叠点位列表，再将 Agent 改为从工作区左侧展开的覆盖抽屉。

DSH 的组合原则要求复用官方 slot、service 与会话组件，没有要求业务 Agent 一定放在右边。左侧放置是轨迹场景的设计选择；现有 Publisher 仍保持右侧，不因本方案改变。

## 1. 依据 DSH 当前实践

以下结论已核对本地 DSH 源码。图中的编辑工具、范围选择和变化反馈是后续设计；当前首步接入左侧原生对话框、固定工作区会话恢复及当前范围摘要。

| 当前规范或实现 | 轨迹布局的采用方式 |
| --- | --- |
| 插件通过官方 slot、service 和 patch 组合，并声明依赖 | 轨迹保留自己的 main 面板；对话由宿主托管，通过声明的扩展能力打开 |
| Publisher 的 Agent 位于工作区右侧，内部渲染官方 Conversation | 轨迹复用其会话托管机制，将业务 Agent 放在工作区左侧；保留原生输入、模型选择、运行状态、工具结果和停止操作 |
| Publisher 使用 simple 模式，空会话只呈现对话 | 轨迹采用同样的纯对话呈现，保留原生输入框与会话控件 |
| 当前抽屉并排宽度 420px；空间不足时变为右侧覆盖层 | 左侧 Agent 首版沿用 420px 宽度；窄窗口改为左侧覆盖，是否并排按地图剩余空间判断 |
| 官方右侧栏与业务 Agent 抽屉由壳层协调 | 打开轨迹 Agent 时暂时收起普通 rightbar，关闭后恢复原偏好 |
| 兼容模式保持官方 layout、sidebar、conversation 组合 | 兼容模式使用原生主会话与官方右侧标签页组合，单独说明降级布局 |

首步由 Desktop 壳层提供按插件、业务范围和请求编号绑定的通用托管入口，支持左右位置；轨迹创建或恢复自己的原生 Session 后请求左侧，Publisher 保持右侧。对话通过 Desktop 拥有的官方 slot 渲染。轨迹通过事件能力协商发现入口，不修改其他插件 DOM，也不借用 Publisher 的文章绑定。

## 2. 宽窗口布局

空间足够时同时显示 Agent、地图和点位列表。最左侧 DSH 导航属于宿主；其右边是整个轨迹插件的 Agent 对话；地图与点位列表构成轨迹工作区。Agent 使用独立标题和分隔线，与全局导航区区分。

```text
+----------------+----------------------------------------+--------------------------------------+--------------------------+
| DSH 侧栏       | 左侧 Agent 对话栏 · 420px              | 轨迹工作区：地图                     | 点位 / 分组列表          |
+----------------+----------------------------------------+--------------------------------------+--------------------------+
| 易宝工坊       | Agent · 轨迹助手             [关闭]    | 武功山反穿   [Agent 已打开]          | [筛选] [折叠列表]        |
| 轨迹           | DSH 会话栏 / 原有模型与模式控件        | [标注点编辑] [线路编辑]              | 金顶组 · 5 个点          |
| 其他插件       | 范围：武功山反穿 · 已选 5 个点         | [选择] [新增] [撤销]                 | 01 金顶                  |
|                | 你：把这些点合成金顶组                 |                                      | 02 休息点                |
|                | AI：已合组，保留各点信息和照片         | 地图 / 轨迹线 / 分组标记             | 03 日出位置              |
|                | [查看变化] [撤销本次]                  | 本次新增、删除、移动的高亮           | 未分组点                 |
|                | 消息区域独立滚动                       |                                      | 06 补给点                |
|                | 原生 DSH 输入框固定在底部              | 海拔剖面 / 里程定位                  | 列表独立滚动             |
|                | 描述需要的修改…              [发送]    |                                      |                          |
+----------------+----------------------------------------+--------------------------------------+--------------------------+
```

- Agent 入口始终放在轨迹页顶部工具栏；空库、列表、线路详情和新建路线页均可打开。所有线路共用固定「轨迹」工作区和会话。关闭左侧 Agent 后，地图自动收回它占用的宽度。
- 点位列表保留现有分组、成员和多选交互；地图点击、多选和列表选择同步到“操作范围”。
- Agent 顶部由壳显示“Agent · 轨迹助手”和关闭入口；模型、模式、附件、发送、停止等控件沿用原生 Conversation。
- 操作范围显示轨迹名、已选数量或组名，可清除选择。范围为只读摘要加轻量操作，不再增加一套编辑表单。
- 对话消息独立滚动，原生输入区固定在对话底部；地图缩放、列表滚动不会推走输入框。
- “查看变化”联动地图与列表定位；“撤销本次”对应一次指令产生的批次。

## 3. 普通窗口布局

Agent 打开后，如果地图、列表和对话无法同时保持可用宽度，先折叠轨迹内部的点位列表。列表通过地图工具栏的“点位列表”入口按需展开。

```text
+----------------+----------------------------------------+--------------------------------------------------+
| DSH 侧栏       | 左侧 Agent 对话栏 · 420px              | 轨迹工作区：保留地图宽度                         |
+----------------+----------------------------------------+--------------------------------------------------+
| 轨迹           | Agent · 轨迹助手             [关闭]    | 武功山反穿 [点位列表] [Agent 已打开]             |
|                | 范围：当前轨迹 · 已选 5 个点           | [标注点编辑] [线路编辑]                          |
|                | 消息与操作结果                         | 地图 / 轨迹线 / 选择与变化高亮                   |
|                | [查看变化] [撤销]                      | 点位列表按需展开，不常驻占宽                     |
|                | 原生 DSH 输入框始终可见                | 海拔剖面 / 里程定位                              |
+----------------+----------------------------------------+--------------------------------------------------+
```

宽度判断使用“轨迹工作区的实际可用宽度”，不使用整个窗口宽度：

- Agent 首版宽度沿用现有 420px。
- 地图、点位列表、间距和对话共同参与空间判断。首版建议地图至少保留约 480px，这个数是设计建议，需在实际窗口验收。
- 地图不足建议宽度时，先折叠约 290px 的点位列表；仍不足时切换到覆盖模式。
- 当前 Publisher 的阈值是中央区域小于 960px 时覆盖。轨迹还包含内部点位列表，因此不能直接照搬该阈值。
- 使用宿主布局状态协调普通 rightbar，保留原有偏好；打开 Agent 时暂时收起普通右栏，避免额外挤压地图。轨迹内部点位列表仍由轨迹插件管理。

## 4. 窄窗口布局

Agent 从轨迹内容区左缘展开，位于 DSH 导航右边，覆盖地图左侧；宽度沿用现有覆盖抽屉的上限 460px，且不超过内容区。图中的“底层”表示被覆盖的轨迹，不是额外的并排列。极窄时铺满内容区，保持原生输入框可见。

```text
+----------------------------------------+--------------------------------+
| 左侧覆盖：原生 Agent 对话              | 底层：轨迹工作区               |
+----------------------------------------+--------------------------------+
| Agent · 轨迹助手             [关闭]    | 当前轨迹 / 地图保留            |
| 范围：当前轨迹 · 已选 5 个点           | 列表已折叠                     |
| 消息与操作结果                         |                                |
| [查看地图] [撤销]                      | [定位变化] 后回到地图          |
| 原生输入框                   [发送]    |                                |
+----------------------------------------+--------------------------------+
```

- 背景轨迹与选择状态保留。关闭抽屉后回到原来的地图位置和缩放。
- “查看地图”或“查看变化”暂时收起对话，回到高亮的修改位置；再次打开恢复会话和输入草稿。
- 覆盖层存在时，被遮挡的控件不能成为键盘焦点；具体采用宿主支持的覆盖层焦点语义。
- Esc 关闭当前最上层界面；存在照片查看器或确认弹窗时优先关闭它们。关闭 Agent 后焦点回到 Agent 入口。
- 关闭、返回、发送与停止入口保持清晰可点；消息增长时不挤占输入区。

## 5. 点位编辑抽屉与 Agent 的关系

Agent 位于左侧，点位和分组编辑保留现有右侧抽屉，因此位置自然分开。现有编辑抽屉是模态 dialog：打开时只能操作编辑抽屉，背景 Agent 不接受输入，不能因为左右分开就让模态失效。

宽窗口可保留左侧 Agent 的背景展示；窄窗口暂时收起 Agent，避免同时出现两个覆盖层。保存或取消编辑后，恢复 Agent、输入草稿与选择状态。

```text
左侧 Agent                  中央地图 / 列表                  右侧编辑抽屉

[对话与操作结果]             点击点位或分组的 [编辑]     ->   点位 / 分组表单
保留会话；模态期间不可输入   地图与选择保留                   [保存] [取消]
恢复对话和输入草稿      <-   更新点位、分组与数据版本     <-   关闭编辑抽屉
[查看变化]              ->   定位本次变化；窄屏暂时收起左侧对话
```

暂时隐藏 Agent 保留 Session、对话草稿和当前范围；隐藏界面本身不等于停止任务。停止运行使用原生停止入口。手动保存后更新操作范围与数据版本，再接受后续 AI 修改。

## 6. 会话与当前范围

整个轨迹插件默认关联一个可恢复的 DSH Session，属于固定「轨迹」工作区。Session 和模型运行沿用宿主；轨迹插件负责轨迹、点位、分组与修改批次。以下发送范围、工具反馈与批次目标仍是后续工具接入设计。

1. 打开 Agent：恢复轨迹插件已关联的有效会话；没有会话才创建。工作区路径固定，不随线路切换。
2. 显示范围：轨迹库数量、当前页面、当前线路、轨迹编号；选中点或组后续接入。
3. 发送指令：把本次操作范围、稳定对象 ID 和数据版本记录进宿主支持的会话上下文机制，让后续恢复能知道本次操作针对什么。
4. 执行反馈：原生工具结果说明完成情况，地图同步更新；消息可提供定位与撤销入口。
5. 切换轨迹：保留同一个会话和未发送草稿，更新当前范围；后续进行中的编辑批次必须针对提交时的轨迹，不随页面切换改目标。
6. 关闭再打开：恢复消息与草稿。切换到其他插件页面时收起轨迹 Agent，按宿主机制处理活动绑定。

## 7. 兼容模式的布局

Desktop 兼容模式没有当前业务 Agent 抽屉。建议采用官方主会话和右侧轨迹标签页，通过已有 slot 组合；这也是需要新增的轨迹适配。

```text
DSH 侧栏              官方主 Conversation           官方 rightbar

轨迹入口              Agent · 轨迹助手              [轨迹] [其他标签]
                      范围：武功山反穿               地图 / 变化预览
                      消息与工具结果                点位 / 分组摘要
                      原生输入框                    [进入完整轨迹编辑]
```

完整轨迹编辑仍在轨迹自己的 main 面板。用户通过“进入完整轨迹编辑”和“返回 Agent”往返，会话与选择保留。该模式延续官方布局，会话本来就位于轨迹右侧标签页的左边；桌面扩展模式才采用本方案的左侧 Agent 对话栏。
