# Track 用户指南

[返回项目首页](../README.md)

本指南按实际使用顺序介绍轨迹、标注、资源和视频工程。安装与开发入口见 [README](../README.md#安装)。

## 导入与查看轨迹

在 e宝工坊侧栏打开「轨迹」，拖入 `.gpx`、`.kml` 或 `.tcx`，也可点击「选择文件」一次导入多个文件。单个文件最多 8 MiB，解析后最多 50 万个轨迹点。

默认名称取文件名并去掉最后的扩展名，例如 `峨眉山.kml` 显示为 `峨眉山`；文件内部路线名不覆盖默认名称，KML 点位各自保留名称。列表按导入时间倒序排列。

点击一条轨迹打开详情：二维地图、地点照片、统计卡片和海拔剖面。点击地图编号或点位列表，打开同一个地点；照片按原始比例显示，可继续查看大图。没有照片或图片加载失败时仍显示地点文字，图片失败可重试。

KML 中的 LineString、MultiLineString、Polygon 和 MultiPolygon 可形成路线。Point 作为标注地点读取，不计入轨迹里程。TCX 中不足两个 Trackpoint 的 Lap 会被跳过。当前不支持 FIT。

详情中的导出入口：

- **导出原文件**：下载导入时保留的文件，逐字节一致。
- **导出 GeoJSON**：下载标准 FeatureCollection，包含路线与起终点，可供其他地图工具使用。

列表和详情均可删除轨迹。确认后删除应用内该轨迹目录及相关浏览器脚本缓存；电脑上原本选取的文件和已经下载的导出文件保留。

## 地图、3D 地图与沙盘

每条轨迹默认打开二维地图。点击「3D 地图」启用在线高程、山体阴影和天空，初始倾角为 60°，支持旋转、缩放、重置与视角恢复。线路编辑和拾点使用二维视图。

点击「3D 沙盘」查看路线范围内的山体、贴地轨迹和起终点：拖动旋转，右键拖动平移，滚轮缩放，也可使用放大、缩小和重置按钮。沙盘按真实米制高程构建，但显示精度仍取决于 DEM 数据分辨率。

从详情页或地图工具栏打开「地图设置」，可配置底图、高程来源、MapTiler Key、地形倍率、建筑、沙盘质量及光影。连接测试、保存、取消与恢复默认不会重置当前页面草稿。

| 内容 | 默认来源或选项 | 网络与 Key |
| --- | --- | --- |
| 矢量底图 | OpenFreeMap | 需要联网，无需 Key。 |
| 地形底图 | OpenTopoMap | 需要联网，无需 Key。 |
| 卫星影像 | Esri World Imagery | 需要联网，当前接口无需配置 Key。 |
| 无底图 | 纯色背景与轨迹 | 二维可离线使用。 |
| 其他地图源 | OpenStreetMap、MapTiler 街道/户外/卫星 | 需要联网，MapTiler 需自有 Key。 |
| 区域高程 | Mapterhorn，或 MapTiler Terrain RGB | 需要联网，MapTiler 高程需 Key。 |

二维地图不请求高程；进入 3D 地图或沙盘才加载区域 DEM。底图失败时退回纯色背景，轨迹与剖面继续可用。OpenStreetMap 公共标准瓦片只用于可见交互地图，不用于沙盘离屏贴图采样。

沙盘范围按路线外扩 20%，每边至少 150 米。底图失败时仍可显示地形着色；高程失败、加载超时或图形上下文丢失时返回二维，并提供「重试沙盘」。更换底图重新生成贴图，离开沙盘释放渲染资源。

沙盘质量默认为「标准」，可选节能、标准、精细。网格最长边分别为 96 / 192 / 256，贴图最长边为 1024 / 2048 / 4096 px，并受实际 GPU 能力限制。地形倍率默认 1.25，可调 1–3 倍。

「光影」可调整太阳方位、高度、主光、环境光与阴影。默认方位 315°、高度 35°、主光 2、环境光 0.65；节能档关闭阴影。调光只更新显示，不重新请求地图或高程；恢复默认光影保留地图源、质量、倍率和视角。

地图、沙盘和视频输出保留实际数据源署名，MapTiler 输出带服务标志。卫星影像清晰度与拍摄时间因区域而异，当前不提供离线批量下载。

地图设置使用当前浏览器的本地存储，Key 默认掩码显示，不写入轨迹文件或 Agent 上下文。可选的天地图 Key 目前仅保存配置，位置反查尚未接入；连接测试仍检查底图与高程。

## 统计与海拔剖面

- 有海拔的路段按坡面长度计算距离，缺失海拔的路段使用水平距离。
- 爬升和下降先对海拔做五点中值滤波，缺失海拔不当作零；最高点和最低点使用原始海拔。
- 时长优先使用轨迹点时间；缺失时可读取 KML 明确标注单位的总览耗时，显示到秒。
- 均速由距离除以该时长，包含时间范围内的停留；没有可靠时间时显示「-」。

文件没有海拔时不补造剖面。沙盘可按 DEM 显示贴地路线，但不会改写文件海拔、统计或剖面。线路编辑中新加或移动的点没有自动补高，缺口不会画成海平面。

标注点按最近路线位置显示在海拔曲线上，编号与地图、列表对应。点击剖面标记会选中同一地点；密集点可展开选择，缩放和平移时标记随曲线更新。剖面初始化失败只影响该区域，可点击「重试剖面」。

## 编辑线路

打开详情 →「编辑当前轨迹」。默认进入「标注点编辑」，也可切换「SVG 标注」或「线路编辑」。切换页签保留草稿，退出时统一处理未保存修改。列表页「新建路线」直接进入线路编辑。

线路编辑支持连点、拖点、手绘补线、插入与删除、两点直连、内部点拆分、按列表顺序合并库中轨迹、反向，以及撤销/重做。需要精确定位时，可使用点序号与经纬度表单。

保存结果是新的 GPX 副本，原轨迹与原文件保留。拆分得到的多个副本一起保存；本批保存失败时回滚新副本并保留草稿。未移动的点保留原有海拔和时间，新增或移动的点对应数据为空。

## 标注点、分组与照片

在「标注点编辑」维护名称、描述、多选类型、真实坐标、照片、排序、分组和显隐。地图、剖面、SVG 与视频素材使用这份地点信息。

Ctrl / Cmd 点击多选已有分组后，可点击「合并分组」或使用右键菜单。按列表顺序保留第一个分组名称，描述用空行连接，成员点和照片保留，可撤销/重做。

展开分组时，成员显示在原始地图坐标；收起后隐藏成员。分组和成员继续遵循各自显隐设置。

照片支持 HTTP(S) 链接或「添加本地图片」，可上传 JPEG、PNG、WebP、GIF、AVIF；单张最多 20 MiB，每个点位最多 30 张。上传后点击保存才关联到点位。本地文件复制到轨迹目录，不修改原照片。

远程照片会缓存源图并生成等比例小图，最长边 1024 px、JPEG 质量 80，处理图片方向且不放大。列表、地图详情和编辑画布优先加载小图，查看大图读取缓存原图。重复引用复用缓存，分组、撤销与转移不改变逻辑来源链接。

图片任务最多并行处理 3 张，单张失败可独立重试。已缓存照片可离线查看；远程地址实际提供的文件决定源图质量。删除整条轨迹同时移除该轨迹缓存。

## SVG 路线图

从「编辑当前轨迹 → SVG 标注」进入。左侧是画布，右侧是点位列表，点击点位调整样式、画布位置与照片布局。

来源点位的名称、描述、类型和真实坐标仍在「标注点编辑」中维护。SVG 同步源点位显隐，分组只展示分组节点，不重复绘制成员；拖动画布上的标记不会移动真实地图坐标。

普通标注默认隐藏，打卡、休息、厕所和补给类型默认显示；手动显隐优先于类型默认值。隐藏点保留在列表，其照片和连接线也随点隐藏，导出遵循同样规则。

### 排版与样式

- 拖动文字、标记或照片独立调整布局，连接线随位置更新；也可用方向键与坐标表单微调。
- 拖动空白区域或选择「拖动轨迹」，移动整组路线内容；滚轮和「轨迹缩放」调整大小，「重置轨迹」恢复默认。
- 「统一样式」控制字体、字号、颜色、编号、标记、连接线、照片尺寸与边框、路线和背景。单个元素可覆盖样式，并逐项恢复继承。
- 整组路线、标记、照片和连接线一起移动/缩放；标题、统计和方向说明保持独立。
- 布局和样式均支持撤销/重做，保存后可继续编辑，原轨迹坐标和原文件保留。

画布默认 1200 × 900，提供 4:3、1:1、16:9、3:4、9:16 及自定义尺寸（240–4096 px）。「适配画布」把可见路线与标注整体放入画布，不重写局部排版位置。

最多 100 个标注、20 张画布照片，嵌入照片总量最多 8 MiB。照片会压缩并嵌入 SVG；可选择点位已有图片或上传本地 PNG/JPEG/WebP。

### 保存与输出

- **保存画布**：保存可编辑的布局和样式。
- **导出 SVG**：输出路线、标记、照片、连接线与端点符号，不包含标题、里程统计、起终点文字和方向说明。
- **导出轨迹 SVG**：单独输出透明路线图层。
- **保存到资源库**：将当前草稿的同一导出画面输出为 PNG，来源为「SVG 标注」，不替代保存画布。

相同图片去重，新布局保存为新资源，不覆盖已有引用。PNG 入库失败可重试当时导出的版本。

## 资源库与地图截图

从轨迹详情打开「资源库」，管理当前线路的图片、视频和音频。已保存的点位、分组、SVG 和视频素材照片可以复用，无须重复导入。

支持多文件导入、逐项进度和失败重试；按类型、来源、用途搜索筛选，切换网格/列表，修改名称和标签，批量追加标签。视频和音频使用原生播放器，具体编码是否可播放取决于当前浏览器。

| 资源类型 | 单文件上限 |
| --- | --- |
| 图片 | 20 MiB |
| 视频 | 2 GiB |
| 音频 | 512 MiB |

文件格式按实际字节校验。不能预览的媒体仍可整理与下载；被点位、SVG 或视频素材引用的资源受删除保护，先解除用途再移除。移除图片条目不立即回收历史撤销所需的照片文件。

二维地图、3D 地图和沙盘均可「保存到资源库」：输出当前视角、路线、已显示标记和来源署名，不包括工具按钮或详情弹窗。图片标记为「地图导出」，并注明对应视图。

地图须加载完成；未保存线路或定位过程中无法导出。相同视图的相同图片去重，新视角保存为独立资源。入库失败可重试当时截取的 PNG。

资源可登记为视频插图、片段、旁白、环境声或背景音乐，视频制作中查看选用清单。目前素材登记不等于已加入合成时间轴。

## AI 图片创作与历史

在资源详情点击「AI 图片创作」，或多选图片后点击「用所选图片创作」。未选图片也可进入创作页，使用文字生成新图片。

左侧预览结果，右侧配置主体/效果参考、提示词、模板与模型。参考图可多选、上传、排序、调整角色和主图；提示词模板可自行新建、编辑、复制或保存。参考 e图宝案例时只填入明确选择的内容，案例展示图不会自动提交给模型。

提示词优化是可选操作，可取消，优化结果由用户审阅后采用。点击「生成图片」才提交任务；结果先保存为候选，确认后进入正式资源库并可追加到点位或登记视频用途，不自动覆盖原照片。

模型与服务由宿主提供，不另存生图账号密钥。可用设置按模型目录能力显示；宿主参考图转发上限为 5 张、单张 10 MiB，请求 JSON 合计上限 24 MiB，上游模型可能有更严格限制。

「历史记录」显示任务生成图，恢复时带回主体/效果参考、顺序、提示词、模型、通道、模板版本和输出设置。恢复本身不提交，再次生成建立新任务，旧输入快照保留。缺失参考图、失效模型或不支持的设置会阻止无效提交，需明确调整。

草稿按轨迹保存在当前浏览器，资源与任务记录保存在本机轨迹目录。切换资源库、创作、历史和视频页面保留输入。网络中断或提交状态不明时先核对原任务，不自动再次生成；结果已生成但保存失败时重试保存原结果。

真实生成质量、费用与可用能力由所选服务和模型决定。功能协议与历史恢复的验证范围见 [AI 图片创作验收](track-ai-image-workspace-validation-v2.md)。

## 镜头工作台与视频策划

在详情打开「轨迹视频制作」，默认进入「镜头编辑」。顶部切换「素材准备」「脚本策划」「镜头编辑」，场景按钮切换地图与 3D 沙盘。

### 素材准备

从真实路线、有效点位/分组、已保存 SVG、关联图片和资源库清单整理素材。确认显示标记、沿线补点、拆分/合并路线、选图，以及分段介绍和路线信息，再点击「用所选素材编排镜头」。

素材独立保存。应用到地图镜头时保留相机构图与输出配置，可撤销恢复原工程。

### 镜头编辑与输出

地图与沙盘共用图层、预览、属性和多轨时间轴。可编辑相机、路线进度、地点与字幕显示区间，拖动关键帧或片段、裁剪区间、缩放时间轴、按帧吸附、时间输入与微调，并支持播放和撤销/重做。

先构图并记录视角，检查时间轴运动，点击「保存工程」，再输出视频。地图与沙盘保存独立工程；JSON 备份和视频下载不替代工程保存。来源变化、读取失败或修订冲突时原工程保留，不自动覆盖。

地图以固定时间戳逐帧编码 VP9 WebM，支持横/竖屏和帧率选择。沙盘实时录制无声 WebM，当前 1280 × 720、目标 30 fps，实际帧率随设备负载变化。输出可取消，预览和视频保留实际地图来源署名。

当前没有原生 MP4 输出，也未接入音乐、旁白混音或普通视频片段的整片合成。更多工程操作见 [镜头工作台](track-shot-editor.md)。

### OpenMontage 策划

「脚本策划」连接本机 OpenMontage 原生 Backlot。需先准备其源码与 Python 环境，在连接设置填写源码绝对路径和 Python 可执行文件。插件不内置 OpenMontage，不自动安装缺失依赖。

选择或创建当前轨迹的独立项目，通过项目 Agent 先确认主目标、观众收获、素材范围与制作规格，再依次确认大纲、脚本、分镜。每阶段等待用户明确确认，成果修改后相关下游确认需重新核对。

批准后，从镜头清单进入地图或沙盘，工程按项目和分镜独立保存。先保存工程并输出真实视频，再点击「回填当前分镜素材」。回填使用 FFprobe 检测文件，将视频登记到原生素材清单和 Track 资源库，保留历史版本。

回填失败或冲突时仍可下载视频并重试。未回填的视频在当前工作区内保留；关闭工作区会释放内存视频，需要长期保留时先下载或回填。已保存项目与视频不依赖浏览器内存。

本机看板与项目文件在本地运行，Agent 策划仍使用宿主模型服务。旧浏览器视频脚本只提供兼容备份，不自动转换为已确认的 OpenMontage 项目。详见 [视频策划](track-video-script.md) 和 [OpenMontage 接入](track-openmontage.md)。

### 轨迹动画录制

详情还有独立「轨迹动画录制」入口。主动选择文本模型生成镜头脚本，审阅采用后可播放全景、沿线跟随和点位聚焦；支持暂停、继续、重播与跳转，录制时固定脚本与底图。

输出 WebM，包含地图署名、路线进度和镜头字幕。没有文件时间或海拔也可按路径距离与脚本时长播放，不请求设备定位。浏览器缺少 MediaRecorder/captureStream 时仍可播放；无 WebGL 时提示能力限制。

## 线路 Agent 与图片引用

顶部「Agent」打开宿主原生对话。每条已保存轨迹按稳定 ID 使用独立项目目录和会话；切换线路切换项目，返回恢复对应对话与未发送草稿。同一线路在详情、编辑、资源库和图片创作之间继续使用同一会话。

列表及未保存的新路线使用公共「轨迹」工作区。宽窗口并排显示，窄窗口显示左侧覆盖层；原生模型、输入与发送/停止控件由宿主提供。旧宿主不支持所需能力时入口禁用并说明原因。

项目中的 `track-context.json` 更新线路与页面参考快照。未保存的路线内容、选中点位/分组尚未同步，当前也没有 Agent 直接增删改轨迹和点位的专用工具。

图片详情提供「复制图片引用」及「添加到 Agent」。前者准备真实本地副本并复制引用与读取指令；后者追加到当前线路原生对话草稿，保留已有文字和附件，不自动发送。模型和工具须支持图片读取，用户手动发送后才能分析。

图片副本保留比例与方向，最长边不超过 2048 px。相同项目、来源与内容复用副本；换线路不会混入另一项目草稿。更多边界见 [Agent 图片引用](track-image-agent-references.md)。

## 数据保存与备份

`<DSH home>` 指宿主使用的 DSH 数据目录。插件沿用宿主目录规则与当前环境；未指定时通常使用 `~/.dsh`，也可通过 `DSH_HOME` 指定独立目录。

```text
<DSH home>/
├── track/<trackId>/
│   ├── track.json                 解析后的坐标、元数据与原始点位
│   ├── source.<gpx|kml|tcx>        导入原文件
│   ├── placemark-state.json       点位、顺序、分组与显隐
│   ├── annotations.json           SVG 布局、样式与嵌入照片
│   ├── geomotion-project.json     单线路地图镜头工程
│   ├── shot-editor-project.json   单线路沙盘镜头工程
│   ├── video-materials.json       视频素材准备
│   ├── resources.json             资源索引与 AI 任务记录
│   ├── placemark-photos/          点位、资源图片副本
│   ├── placemark-thumbnails/      缩略图
│   ├── placemark-photo-assets/    图片来源与处理状态
│   └── media/                     视频和音频文件
├── track-agent/
│   ├── agent-session.json         公共工作区会话关联
│   ├── 轨迹/                      公共上下文与图片引用
│   ├── tracks/<trackId>/          线路会话、上下文和图片引用
│   └── openmontage/projects/      策划项目、分镜工程与历史视频
└── track-resource-templates/
    └── templates.json             个人提示词模板
```

镜头保存到 OpenMontage 项目时位于对应项目的分镜目录，与上图单线路工程隔离。Agent 项目包含 `AGENTS.md`、`track-context.json`、`agent-session.json` 和选中的 `image-references/`；改名不改变线路项目 ID，已有用户指令与历史目录保留。

地图配置（包括可选 Key）、AI 创作草稿、部分旧动画/脚本缓存存于当前浏览器的 localStorage；已保存路线和镜头工程不只存浏览器。迁移时先保存工程、导出需要的 JSON/视频，并备份 DSH 数据目录与对应应用 Profile。

个人模板独立于轨迹保存，删除一条线路不会删除整个个人模板库。原始文件、用户照片、Profile、缓存与输出视频不随 npm 包发布。

## 离线与故障恢复

本地轨迹线、统计、海拔剖面、线路/点位编辑、SVG、本地媒体与已缓存照片可离线使用。底图、卫星与区域高程需联网；AI 图片、提示词优化和 Agent 模型请求需可用宿主服务。

- **地图空白**：切到「无底图」，在地图设置中测试服务。无 WebGL 时以 SVG 折线降级显示，仍可查看轨迹形状和海拔。
- **沙盘失败**：返回二维后点击「重试沙盘」，检查高程服务和设备图形能力。
- **照片失败**：单项重试；需要读取跨域源图时可上传本地图片，不覆盖已有照片。
- **AI 服务不可用**：资源管理继续可用。保留草稿，核对历史任务，确认后再提交。
- **工程冲突或损坏**：保留原工程，使用「下载原工程备份」或导出当前 JSON，再明确选择后续处理。
- **Agent 入口不可用**：更新至支持项目会话的 Desktop，插件或宿主升级后重启应用。
- **OpenMontage 检测失败**：按连接设置显示的问题检查源码、Python 与所需依赖；回填另需 FFprobe。

本地 Track 服务只监听回环地址，变更请求有同源与专用请求头保护。导入、打开和编辑线路不会采集实时位置。
