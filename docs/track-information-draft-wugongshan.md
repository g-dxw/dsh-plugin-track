## 一、入口与用途

在轨迹详情中增加「路线信息整理」，放在「编辑轨迹」和「轨迹视频」之间：

**编辑轨迹 → 路线信息整理 → 轨迹视频**

交互按 Agent 资料工作区调整：入口打开本条路线的原生 Agent 会话，并展开宿主「文件」组件。Agent 通过对话完善资料，Markdown、图片和附件保存到当前路线工作区，文件列表实时显示结果，点击文件使用原生预览阅读。以下内容是可由 Agent 核对、补充和整理的资料结构，不再作为手填表单。


这个页面把当前轨迹的数据、沿途点位、环境背景和行程补充资料整理成一份可以阅读、补充和导出的路线资料。用户先在这里看清这条路线，再将需要的信息用于轨迹视频。

页面重点回答：这条路线在哪里、走多远、经过哪些地方、沿途是什么环境，以及还有哪些信息需要补充。

建议内容顺序：**轨迹概览 → 基础信息 → 路线与点位 → 环境信息 → 行程补充 → 信息来源**。

## 七、整理与使用方式

### 7.1 已有信息自动汇总

基础统计跟随当前轨迹；点位名称、说明、分组、图片及显隐状态跟随「编辑轨迹」。需要修改点位时，返回对应的点位编辑入口。

### 7.2 补充路线资料

路线简介、环境记录、行程经验和核实资料可以补充。自动取得的数据、用户填写的内容和外部来源，在需要时显示来源标签。

### 7.3 AI 整理

在 Agent 中提出「完善路线资料」：根据真实基础数据、有效点位及用户补充资料更新工作区 Markdown，文件组件同步显示保存结果。缺少依据的部分保留为待补充或待核实。

### 7.4 导出与视频引用

可提供「复制 Markdown」「导出 Markdown」，并让「轨迹视频」引用已整理的信息。后续视频创作可以从这份资料选取路线数据、节点说明和环境内容。
