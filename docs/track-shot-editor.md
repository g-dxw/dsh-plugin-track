# 统一镜头编辑工作台

入口：打开轨迹 → 轨迹视频制作，默认进入「镜头编辑」。顶部页签切换素材准备、脚本策划、镜头编辑；场景按钮切换地图和 3D 沙盘。

两种场景共用左侧图层、中央预览、右侧属性与底部多轨时间轴。相机、路线进度与地名/字幕显示区间分别编辑，支持关键帧拖动、按帧吸附、时间微调和撤销重做。参数与关键帧保留在各自工程内，切换场景暂停播放并保留编辑状态。

构图后记录当前视角，在时间轴检查运动与路线显现，再点击「保存工程」。保存工程写入轨迹目录，视频输出和 JSON 导出不替代工程保存。切换或退出遇到未保存修改时，可保存后继续、放弃本次修改或取消。读取失败、修订冲突、来源指纹不匹配时保留原工程及 JSON 备份能力，不自动建立默认镜头覆盖。

## 工程文件

- 地图沿用 `geomotion-project.json` 与 GeoMotion 格式；经纬度、缩放、朝向、俯仰及所有通道轨道保持原样。
- 沙盘使用独立 `shot-editor-project.json`，保留版本 1 的 `plan`、`appearance`，追加保存修订号与时间。相机为场景米制的 position、target、fov；路线进度关键帧、地名、字幕与场景外观独立保存。
- 首次没有沙盘工程时，读取旧 `cqai-track.shot-editor.<trackId>` 浏览器草稿，合法草稿恢复为待保存。点击保存后完成迁移，旧浏览器数据保留。已有工作区工程优先。
- JSON 导入继续兼容旧沙盘格式；工程上限 2 MB。地图继续使用现有格式及 16 MiB 上限。地图 Key 不写入工程或备份。
- 「工程文件」中的「下载原工程备份」直接下载已保存文件的原始内容，读取或解析失败时仍可使用；「导出 JSON」备份当前编辑状态。

## 场景与输出

地图支持底图、三维地形和逐帧 WebM 输出，使用原有画面尺寸与帧率设置。沙盘沿用 DEM/Three.js 渲染、地形配色和场景光照，支持 1280 × 720、目标 30 fps 的实时无声 WebM，实际帧率随设备负载变化。预览、视频输出进度和取消入口采用相同工作台。

从窄窗口的属性或图层面板输出视频，会先切回预览并等待画布尺寸稳定。准备和录制期间禁止切换场景，可取消输出。

更换沙盘底图、地形提供商、采样质量或垂直夸张可能改变场景身份；旧工程保留且可备份，重建需要明确操作。来源署名与所需地图服务标志继续进入预览及录制。

素材准备整理路线、地点、图片、介绍和资源库选用清单，保存确认后可进入地图场景应用素材；脚本策划独立确认内容与旁白。进入页面不自动录制或调用 AI。

## OpenMontage 项目镜头

脚本策划嵌入本机 OpenMontage 原看板。大纲、脚本和分镜分别确认后，从外侧制作清单进入地图或沙盘。项目镜头按 projectId/shotId 独立保存，与轨迹单例工程隔离；再次进入恢复已有关键帧。

项目镜头先保存，再输出视频并点击「回填当前分镜素材」。回填冻结工程修订和分镜成果摘要，失败或冲突保留视频下载；旧录制版本仍可预览。部分回填不完成整片素材阶段，详见 [OpenMontage 接入](track-openmontage.md)。
