# 三维镜头编辑器

入口：打开轨迹 → 轨迹视频制作 → 三维镜头编辑。

1. 等待真实 DEM 与底图加载，拖动画面旋转，滚轮缩放，右键平移。
2. 在时间轴选择时间，构图后点击“保存当前视角”。已有相同时间的关键帧会被替换。
3. 点击关键帧时间按钮可查看该帧，输入时间、方向、俯仰、距离和视野角度可精确调整；缓动作用于这一帧到下一帧的区间。
4. 相机轨和路线轨分别设置。路线百分比使用已贴合 DEM 的原路线，保留原始分段。
5. 添加已有点位或分组的地名，设置各自出现和结束时间；字幕单独设置时段。编辑光照和背景后直接预览。
6. 播放检查，保存草稿或导出 JSON。导入仅接受匹配轨迹和三维场景的版本 1 配置。
7. 点击“录制镜头 WebM”，从 0 秒录制至镜头结束，最后一帧保留约 150 毫秒。参数与底图在录制期间固定。结果可回放、下载，并导出本次录制参数。

总时长编辑范围 3–120 秒，调整时长会同比缩放所有关键帧和显示时段。默认镜头为 20 秒：相机缓慢转向、拉远；路线先等待再显现。浏览器本地存储键为 `cqai-track.shot-editor.<trackId>`，镜头修改自动保存，可撤销最近 30 次镜头数据修改；光照修改独立保存。原轨迹、点位安排和正式脚本不会因本编辑器写入。

真实采样沿用地图设置：免费 Mapterhorn DEM 优先，MapTiler 可选。底图不可用时明确提示并使用地形配色。更换底图、地形提供商、采样质量或垂直夸张会改变场景身份，旧草稿缓存保留，需要重新建立镜头。来源文字和所需 MapTiler 标志同时进入预览与录制；配置中不导出地图 Key。

当前交付支持单个镜头、1280×720、目标 30 fps 的实时无声 WebM，实际帧率随设备负载变化。旁白、音乐、多镜头剪辑与插件内 MP4 编码尚未接入。

实现：`src/client/ShotEditor.tsx`（操作、草稿、录制），`ShotEditorScene.tsx`（真实采样与合成），`src/track/shot-editor.ts`（纯时间轴求值），以及现有 SandboxRenderer 的绝对相机/路线裁剪接口。三维捕获画布与界面叠加使用相同帧数据，反向拖动进度不会依赖播放历史。
