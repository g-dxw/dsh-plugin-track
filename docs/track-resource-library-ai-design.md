# 轨迹资源库与 AI 图片工作台设计

日期：2026-10-05  
状态：第一期已按本方案实现。实现范围与验证记录见 [验收文档](track-resource-library-ai-validation.md)。

## 1. 已确认的目标

用户已经确认：

- **真实照片美化优先，兼顾文字生图。**
- **第一期同时管理图片、视频、音频。**
- **复用 DSH 已有 AI 服务。**
- **资源库使用独立界面，从轨迹详情进入。**
- **提示词预设默认空白，用户自行添加；可参考 e图宝模板库。**

在轨迹详情增加「资源库」按钮，打开当前轨迹的独立资源工作区，集中管理这次旅程的素材。资源库拥有自己的标题、导航、工具栏和主要内容区域；进入后显示完整的资源管理界面。右侧提供随素材类型变化的工作台；图片可以直接进入 AI 美化，也可以通过独立入口生成新图片。生成结果保留来源和版本，再由用户选择用于点位、轨迹展示或视频制作。

第一期图片、视频、音频都要能导入、整理、预览和登记用途。AI 功能先围绕图片展开；视频和音频的管理不依赖 AI 服务是否可用。

## 2. 实施前项目基础与缺口

本节记录方案制定时、实施前的工作区源码检查结果。实施后的行为见验收文档；未验证已安装 DSH 的运行状态。

| 项目 | 当前基础 | 对本次设计的影响 |
|---|---|---|
| 轨迹详情 | 标题、指标卡片、地图与点位，以及视频制作等操作 | 详情增加资源库入口，打开关联当前轨迹的独立页面 |
| 点位照片 | 支持本地图片和链接；已有原图、缩略图与缓存处理 | 将正式关联的照片登记进资源库，无须重复导入 |
| 生图适配 | `src/client/imagegen.ts` 已有模型目录、单图编辑、任务提交/查询/取消 | 优先复用宿主服务；资源库不另建 Key 配置 |
| 当前 AI 界面 | 当前源码没有调用上述生图适配的页面 | 需要补齐完整的图片工作台与任务持久化 |
| 当前生图请求 | 固定单参考图编辑、单张输出、尺寸与质量自动 | 文生图、画幅控制、批量输出等需要核验宿主能力 |
| 视频素材准备 | 目前围绕轨迹地点、分段、文字和地点照片组织 | 增加通用媒体引用；普通视频片段与音频需要额外接入 |
| 当前地图视频导出 | 绘制地图与图片到画布，未接外部视频帧或音频轨道 | 素材管理与后续混剪、混音分别验收 |
| 通用媒体库 | 尚无统一的图片/视频/音频资源索引 | 新增资源层，把素材文件、点位关联、视频用途分开保存 |

现有图片适配是可复用的基础。此次补充检查确认 e图宝宿主源码协议已有文生图与图片编辑模式；Track 当前适配仅暴露单图编辑。文字生图仍是本次目标，接入时需要扩展 Track 适配，并核验运行中的宿主版本与模型能力。

## 3. 信息结构

### 3.1 三种素材类型，独立的来源和用途

资源库顶层使用「全部 / 图片 / 视频 / 音频」筛选。来源和用途是另外两个维度，一张照片可以同时属于某个点位，并被选作视频插图。

| 维度 | 建议内容 |
|---|---|
| 类型 | 图片、视频、音频 |
| 来源 | 轨迹已有照片、本地导入、链接导入、地图导出、AI 美化、AI 生成 |
| 用途 | 点位照片、分组封面、视频插图、片段、旁白、环境声、背景音乐 |
| 整理 | 精选、标签、关联点位、未使用 |
| AI 结果 | 待选、已保存；是否已使用由用途关系体现，不覆盖素材类型 |

「设为轨迹封面」可以作为扩展用途，但目前轨迹记录还没有封面字段，需要一起设计列表展示与持久化。第一期优先完成已有点位照片和视频素材的复用。

### 3.2 原有照片如何进入资源库

- 首次打开时，登记已保存的点位、分组和 SVG 中的照片来源；同一文件或同一来源可关联多个位置。
- 不将磁盘上的未保存上传草稿自动列成正式素材。
- 隐藏点位的照片仍可在资源库整理，并标明关联点位已隐藏；这不会改变地图或 SVG 的显示状态。
- 分组封面与成员照片保留各自关系。选择新封面不自动替换成员原图。
- 链接图片保留原始 URL。缩略图按需加载；进入美化或视频使用时准备本地副本，并标明本地保存状态。
- 手动导入的素材可以暂时不关联地点。缺少拍摄时间或坐标时不自动猜测归属。

点击「资源库」进入该轨迹的独立页面。点击点位照片的「AI 美化」时，同样打开资源库，并选中**这一张照片**、打开右侧 AI 工作台，保留点位上下文；同一点位有多张照片时，由用户先选图。没有照片时提示添加照片，不拿整个地图或其他点位的照片代替。

独立界面仍属于当前轨迹的素材管理。页面标题和面包屑显示所属轨迹，避免误把素材添加到其他旅程。第一期沿用每条轨迹的资源归属；跨轨迹总库可以以后扩展。

离开轨迹详情前保留地图位置、缩放、点位选择和页面滚动位置，点击资源库页的「返回轨迹详情」后恢复。资源库内部进入预览或图片编辑时，返回目标是资源库，并恢复筛选、排序、滚动位置和所选资源。生成任务继续后台运行；完成通知携带所属轨迹与资源上下文，点击后打开对应结果。

## 5. 关键操作流程

### 5.1 导入和整理

```text
打开资源库 → 登记已有正式照片 → 导入图片/视频/音频
           → 逐项落盘 → 补充缩略图/时长 → 标签、精选与用途
```

混合文件可以一次导入。逐项显示状态，成功项即时可用；失败项显示原因并可单独重试，不让一个失败文件导致整批重导。复制到插件管理的数据目录后登记资源，不长期依赖临时文件路径。

复制进度与元数据提取进度分开显示。视频封面和音频时长在后台补全，导入列表不等待所有媒体解码完成。

### 5.2 照片美化

```text
选择照片 → 直接输入要求 / 选择自建模板 → 确认参考图与模型 → 开始美化
         → 候选结果对比 → 保存到资源库 → 选择用途
```

提交时冻结轨迹、参考图、原图版本、完整提示词和模型；使用模板时额外冻结模板 ID 与版本。生成中允许返回库和切换轨迹；结果始终归属于提交时的轨迹与原图。

成功候选先持久化到「待选结果」，关闭页面后可恢复。点击保存后成为正式资源；丢弃候选属于另一项操作，清理规则必须显式可见。

模板默认不选。选择模板只填入要求，不触发生成；没有模板也能直接输入要求进行美化或生图。第一期一次生成一张；「再生成」是一次新的明确提交。

### 5.3 用于轨迹与视频

| 素材 | 用于轨迹 | 用于视频 |
|---|---|---|
| 原照片 / AI 美化图 | 添加到指定点位；选择展示图；选择分组封面 | 插图、片头背景、章节画面 |
| AI 生成图 | 用户明确选择后可作为展示图片，保留 AI 来源标记 | 封面背景、氛围插图、过渡画面 |
| 视频 | 关联点位作为旅程附件，不自动改变轨迹数据 | 实拍片段、补充画面 |
| 音频 | 关联点位作为环境记录 | 环境声、旁白、背景音乐 |

「添加到点位」默认追加一张图片；「替换当前展示图」是独立操作，并保留恢复原图的能力。

「加入视频素材清单」首期保存素材引用、用途与备注，并在视频制作页查看和预览入选素材。它表示素材已进入该轨迹的制作清单，**不表示已经进入时间轴或生成视频**。现有二维视频素材页可增加「从资源库选择图片」；普通视频片段和音轨的时间轴接入另外分期。

未来图生视频可以从这张图创建新任务，并把结果登记为视频资源，继承来源关系。此次方案不要求提前选择视频生成服务。

## 6. 用户自建提示词模板

### 6.1 默认空白

首次使用时「我的模板」清单为空，不预装徒步、旅行或其他提示词。已移除上一版内置预设清单和成套提示词。

- 用户可以新建、编辑、复制、删除自己的模板。
- 可以把本次填写的提示词「保存为模板」。
- 可以参考 e图宝已有案例，修改后另存到「我的模板」。
- 参考案例与用户自己的模板分开显示，浏览参考库不会增加我的模板数量。
- 未创建模板时，直接填写提示词仍可生成；模板不是必填项。
- 建议我的模板在同一 DSH Profile 内跨轨迹复用；资源文件继续归属于各自轨迹。

### 6.5 套用与另存流程

```text
手动新建：填写名称/模式/提示词 → 保存我的模板
本次输入：输入提示词 → 保存为模板 → 下次选择复用
参考案例：浏览 e图宝 → 查看提示词与示例 → 编辑副本 → 保存我的模板
本次套用：选择模板 → 填入提示词 → 按需修改 → 点击开始美化/生成
```

参考详情提供「填入本次提示词」与「编辑并保存为我的模板」两项操作。前者不会创建模板，后者经保存才增加我的模板条目；两者都不自动触发生成。

套用模板保持当前生成模式与参考照片，按适用模式筛选我的模板；模式不兼容时提示用户选择用途。e图宝当前主页面套用模板会切到文生图，Track 需采用自己的套用回调，不能照搬该自动切换。

提示词框已有手动修改时，套用新模板前提示是否替换当前草稿。已提交任务保存自己的提示词与模板版本快照，后续编辑或删除模板不改变历史任务和生成结果。

### 6.6 保存与接入边界

我的模板新增个人模板记录：ID、名称、适用模式、完整提示词、标签、可选示例图、来源案例标识与来源链接、版本、创建/修改时间。模板位于用户模板集合，删除某条轨迹不删除个人模板。

e图宝现有 `TemplateCase` 的名称、提示词、分类、风格/场景标签、作者和来源可作为参考字段。Track 的模板模式与用户编辑版本是新增信息；不假定 e图宝已经提供用户自建模板的 CRUD 接口。

优先通过宿主已有模板读取接口浏览参考案例。参考不可用时保留手动新建和粘贴提示词；避免依赖另一插件的 DOM 或直接修改它的缓存文件。

路线图、距离和海拔等准确内容继续由现有轨迹渲染与文字排版提供。参考图或创意案例不会自动成为真实路线事实。

## 7. 数据与接入建议

### 7.1 三个独立记录

| 记录 | 建议保存内容 |
|---|---|
| 资源 Asset | ID、所属轨迹、类型、名称、受控文件引用、来源、格式、大小、标签、导入时间 |
| 类型元数据 | 图片尺寸；视频时长/尺寸/封面；音频时长；编码与预览可用状态 |
| 来源关系 | 原始资源 ID、上一级派生资源 ID、AI 美化/生成标记；不伪造拍摄信息 |
| 用途 Usage | 资源 ID、目标点位/分组/视频工程、用途、备注；一个资源可有多个用途 |
| AI 任务 Job | 本地任务 ID、宿主任务 ID、轨迹 ID、参考资源快照、可选模板 ID/版本、完整提示词、模型、状态、结果引用 |

资源文件、资源索引、任务记录分开存储。正式资源与待选结果使用不同状态；原图和派生结果都有稳定 ID。

### 7.2 文件保存与旧数据兼容

- 旧图片继续使用现有照片存储和 URL，通过资源索引引用，无须搬迁字节或批量改写点位。
- 新增通用媒体存储，处理视频/音频上传、受控读取和删除。图片上传接口不能直接承担这两类文件。
- 视频/音频采用流式接收与写入；各类型分别制定上限，不能照搬现有单图 20 MiB 的限制。
- 新媒体需要可分段读取的播放接口，支持 HTTP Range，避免播放大视频时反复下载整段文件。
- 外链图片的原始来源与本地副本分开记录；批量打开资源库不触发全部高清图下载。
- 正式资源索引使用修订号与原子写入；并发冲突保留用户草稿。
- 新视频素材使用资源 ID/文件引用，避免把高清图片、视频或音频字节嵌入 JSON。
- 新图片引用需要兼容现有点位和 SVG 的图片校验；视频、音频链接不能被当成点位照片接受。
- 删除资源前显示现有用途。仍被引用时先处理关联；点位恢复和撤销所需文件不能立即清理。
- 轨迹删除时沿用现有删除确认，同时统计并清理该轨迹新增的正式媒体、待选结果和任务记录。

### 7.3 复用宿主 AI

沿用 DSH 模型目录与账号状态，配置入口指向宿主设置。资源库显示当前模型、服务状态与明确的提交按钮，不另存 API Key。

实施前核验：文生图模式、支持的图片格式/大小、输出尺寸、取消行为、任务保留时长、费用/额度反馈及幂等提交。现有适配没有模型能力字段，必须补充能力识别或经过验证的映射，才能开放相应控件。

网络超时先核对原任务，再决定是否重提；页面离开不取消任务。取消后根据宿主实际状态更新，不承诺未计费。生成成功但本地保存失败时，保留宿主任务 ID 并允许重试保存，避免为了保存再次生成。

## 8. 状态与反馈

| 状态 | 页面行为 |
|---|---|
| 空资源库 | 提示导入图片/视频/音频；文字生图可独立打开 |
| 未选图片 | 美化按钮不可用，说明需要选一张图片 |
| 服务不可用/账号过期 | 资源管理和播放继续可用；AI 区显示宿主状态与设置入口 |
| 文件导入失败 | 保留成功项；逐项显示原因并重试 |
| 编码无法预览 | 保留文件管理与导出入口；不显示假的时长或播放器成功状态 |
| 排队/生成中 | 显示阶段、任务入口与取消；无真实进度时不造百分比 |
| 提交状态不明 | 查询已提交任务，防止重复提交 |
| 生成失败 | 保留参考图和要求，用户明确点击后重试 |
| 生成成功 | 进入可恢复的待选结果，显示比较/保存/丢弃 |
| 保存失败 | 重试保存已有结果，不重新计次生成 |
| 原图或关联点位已删除 | 保留生成结果与原任务来源，不自动绑定到其他点位 |

AI 队列按当前轨迹展示，切换轨迹后仍能从任务入口找到原任务。首次打开我的模板为空，不提交生成，也不自动把候选写入地图或视频工程。

## 9. 建议实施顺序

下面是同一第一期内部的实施顺序，第一期交付仍包括图片、视频、音频管理。

| 步骤 | 交付内容 | 验收重点 |
|---|---|---|
| 1 | 独立资源库页面与返回导航、通用资源索引、旧照片登记、三类文件混合导入 | 旧点位不变；无重复导入；失败项可恢复 |
| 2 | 图片大图、视频播放器、音频试听、搜索/标签/用途 | 实际宿主编码兼容；大文件播放；窄窗口可用 |
| 3 | 单图 AI 美化、空白个人模板库、模板管理与 e图宝参考、持久化任务、结果对比与保存 | 参考图正确；切换轨迹不串任务；原图可恢复 |
| 4 | 核验并接入文字生图；按能力开放画幅等设置 | 无参考图确实可提交；不展示不可用参数 |
| 5 | 点位从库选图、视频素材清单、二维视频素材选图 | 资源引用正确；保存不自动修改其他工程 |

如果宿主目前只支持图片编辑，第 4 步就是需要补齐的接入缺口，应明确列出，不用图片编辑请求假装完成文生图。

后续再接普通视频片段、音轨时间轴、图生视频与批量美化。资源库的第一期管理能力独立成立；后续剪辑继续使用这些资源 ID。

### 首期验收场景

1. 原有多点位/分组/本地与链接照片进入库，地图与 SVG 显隐保持一致。
2. 一次导入图片、视频、音频；成功项保留，失败项单独重试。
3. 图片可比较原图与派生结果；视频可播放/定位；音频可试听/拖动进度。
4. 从点位照片进入美化，提交的始终是用户选中的那张图片。
5. 生成中切换照片、轨迹或关闭页面，回来仍能恢复正确任务和结果。
6. 超时、取消、保存失败不会默默重复生成或覆盖原图。
7. 同一素材用于多个位置；移除一个关联不删除其他用途的文件。
8. 大文件、宿主左侧 Agent 打开、浅色/深色和窄内容区均可操作。
9. 从轨迹详情打开独立资源库，再返回时恢复地图位置与选择；从编辑/预览返回库时恢复筛选和滚动。
10. 首次打开我的模板为空；用户可以手动生成、新建、编辑、复制、删除模板；参考案例只有显式保存后才进入我的模板。

## 10. 视觉和交互约定

继承现有 `--trk-*` / DSH 主题、字号与图标，不增加一套独立品牌配色或外部字体。以图片和播放器为视觉中心，状态使用文字与图标共同表达。

- 操作可用键盘完成；抽屉关闭后焦点返回入口。
- 拖动对比和播放进度都有按钮/键盘替代操作。
- 错误出现在对应文件、字段或任务旁边。
- 缩略图预留尺寸并按需加载，批量素材不同时播放或解码。
- 任务后台运行只提示有意义的完成/失败，不反复弹出状态通知。

本地设计资料未匹配到专门的徒步媒体库产品模板；本版布局基于当前 Track 结构，采用已检索到的键盘导航与进度反馈规则。
