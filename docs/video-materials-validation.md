日期：2026-10-04；分支 `codex/geomotion-integration`。用户确认的范围为：先提取已有轨迹信息，再确认展示标记、划分路线、选择图片、补充路线及分段介绍，最后进入镜头编排。

## 已实现流程

在「轨迹视频制作」案例页或「三维镜头编辑器」点击「二维素材准备」。先读取真实坐标、有效地名/分组、原始连接段、图片候选与已有 SVG 标注；画布默认完整适应路线。

- 地点可勾选、改名、补充介绍、改色、删除、拖动名称；文字偏移仅影响二维排版，地理位置保持来源坐标。
- 可沿实际路线补标记，或在画布/数值框选择拆分点。路线保存真实点范围，不复制几何、不跨原始断点连接或合并。分段名称、介绍、颜色、展示选择可编辑。
- 图片候选来自已关联的点位/分组/SVG。只有主动选择才请求单张像素并嵌入压缩 JPEG，也可上传本地图片。进入准备页和镜头页不触发全部照片预取。
- 里程、爬升、下降、海拔范围和有效记录时长从实际轨迹按连接段计算；可确认显示、调整文字并添加自己的介绍。没有有效时间不会编造时长。
- 素材单独保存，支持撤销/重做、JSON 备份/导入、读取重试、离开保护、重新提取及 409 冲突保护。重新提取可撤销；保存冲突保留内存中的编辑。
- 「用所选素材编排镜头」先保存素材，再生成路线、地点、图片和文字图层。保留原相机节点/关键帧、工程时长、底图、地形、输出宽高和帧率。替换的原素材保存在撤销历史里；镜头存档等明确点击「保存工程」才更新。
- 生成图片依据真实长宽比限制合成高度，照片说明在署名上方；普通导入图片不自动调整。路线统计与分段/地点介绍按所选行数安排初始位置。图片/文字可继续在时间轴控制显示时间。

## SVG 闪烁修复（2026-10-04）

用户在 51218 报告持续闪动。启用实际可见的滚动条后复现：1441×865 窗口、300% 放大时，横向滚动条反复出现/消失，clientHeight 在 498/513 之间交替，SVG 在 948×1422 与 978×1467 之间循环；约 0.9 秒发生 176 次 style 变化。早先 Playwright 默认隐藏滚动条，未覆盖这个真实布局条件。

修复：观察 ResizeObserver 的稳定 border-box 而非受滚动条影响的 client 内容尺寸；尺寸向下取整，适应留出滚动条余量。内部撑满使用 CSS min-width/min-height:100%，不再将测量尺寸回写为内层像素下限。放大后的内容仍可滚动，实际容器变化仍可重新适应。

验证：19 项素材 UI 测试通过，新增滚动条内容尺寸变化与实际容器调整的回归；类型检查和构建通过。没有重复重置原验收工程或素材。`verify-canvas-stability.mjs` 在 1441×865、813×793、390×901 三种窗口与 100/125/150/200/300% 缩放共 15 个场景连续采样，每个场景约 91–92 帧，SVG style 变化全部为 0。回到适应后没有内部溢出，pageerror/console error/warning 为空，没有 API 写入请求，保存素材的哈希不变。

前后证据为 `canvas-classic-before.json`、`canvas-stability-after.json`、`canvas-stability-after.png`；复核脚本不保存或重置用户数据。单一继承配置的 UI 代理只读审查布局反馈，主任务完成实际复现、代码修复、回归与浏览器验收。原浏览器标签页未强制刷新，避免丢失其尚未保存的操作；用户保存后刷新即可加载修复。
## 2026-10-04：画布直接缩放和平移

根因：原素材画布只有工具栏缩放按钮，未接收滚轮/拖动事件；放大依赖内部滚动条，不能像地图一样围绕鼠标操作。

新增原生视图导航 hook，保留实际 SVG/地理投影：滚轮以鼠标为中心缩放（50%–800%）；选择模式可拖动空白，平移工具可拖动任意画布区域；空格或中键临时平移；触屏支持空白单指平移和双指缩放。方向按钮、画布焦点内方向键以及 +/−/0 提供替代操作。适应恢复 100% 和居中。使用原生 passive:false wheel 监听，内部画布不再以滚动条导航，继续按稳定 border-box 测量适应尺寸。

视图状态不进入素材文档、撤销历史或 API；地理坐标与原始分段保持不变。缓存地名投影和分段路径，避免每次视图移动重复处理全部路线。选择模式保留地名拖动，添加/选点模式保留点击真实路线；拖动超过 3px、单指触控拖动和双指缩放均有点击保护，取消/失焦/加载时释放指针捕获。

验证：26 项素材 UI 测试通过（本次新增 7 项），覆盖 wheel 保焦/边界、平移与标签隔离、拖动后点击、键盘/按钮、失焦和加载锁定、双指缩放、add/split 单指拖动与轻触区分；类型检查和构建通过。真实 Chromium 在已有 2191 点路线验证 12 项交互，包括保焦误差 0.005px、50/800% 边界、空格/中键、双指原生触控、放大后新增点的实际坐标与地名拖动、813/390px 窗口操作；没有 API 写请求，素材导出前后相同，sidecar 哈希不变，pageerror/console error/warning 为空。稳定性脚本再次检查 15 个尺寸/缩放场景，每场景约 91–92 帧，style 改变全部为 0。

证据：`outputs/video-materials-verification/verify-canvas-navigation.mjs`、`canvas-navigation-evidence.json`、`canvas-navigation-desktop.png`、`canvas-navigation-mobile.png`；最新稳定性证据仍为 `canvas-stability-after.json`。这些验证脚本不重置或保存用户工程/素材；当前用户标签页未强制刷新，保存后刷新 http://127.0.0.1:51218/ 即可加载。一个继承主任务配置的 UI 代理实现并复查导航 hook，主任务接入界面、补回归并完成真实浏览器/构建验收。
