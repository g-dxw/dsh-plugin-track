# 轨迹 AI 图片创作：提示词优化

状态：已实现。更新：2026-10-06。

在现有独立「AI 图片创作」页面中，复用 DSH 的文本 / 识图模型。模板库提供「优化后使用」，提示词下方提供「继续调整」。有图片时分析全部已选图片内容；没有图片时结合轨迹资料和文字要求改写。结果先预览，用户采用后才填入草稿。

## 模板库入口

```text
提示词模板库                              [关闭]
[我的模板] [参考 e图宝]

┌──────────────────┬───────────────────────────────┐
│ 搜索 / 分类 / 来源 │ 模板详情                      │
│                  │ 模板示例及来源                │
│ 模板列表          │ 原始生图提示词                │
│                  │                               │
│                  │ [修改并另存]                  │
│                  │ [仅填入提示词] [优化后使用]   │
└──────────────────┴───────────────────────────────┘
```

- 「仅填入提示词」沿用直接填入原文的行为。
- 「优化后使用」关闭模板库，打开优化预览，不先覆盖已有草稿。
- 我的模板详情同样提供「优化后使用」，允许把原模板适配为当前素材的新提示词。
- 参考案例图片仅供案例展示；本次分析使用创作页中用户明确选择的主体图、效果图。
- 个人模板清单仍默认为空。优化不自动保存或覆盖模板，需要时通过「保存为模板」独立保存。

## 优化预览

```text
优化后使用 / 继续调整                       [关闭优化]
结合当前轨迹与参考图内容，预览后应用到草稿

┌────────────────────────────────────────────────────┐
│ 当前轨迹名称 · 主体 2 张 · 效果 1 张                 │
│ 基于：所选模板 / 来源                               │
│ [主体1缩略图] [主体2缩略图] [效果3缩略图]             │
└────────────────────────────────────────────────────┘
识图模型 [DSH 可用模型                              ▾]

┌───────────────────────┬────────────────────────────┐
│ 原模板 / 当前提示词    │ 优化结果                   │
│ 只读原文               │ 可编辑提示词               │
│                       │                            │
│ 调整要求               │ 调整说明                   │
│ [输入想继续改的内容]   │ · 根据哪些素材改了什么     │
└───────────────────────┴────────────────────────────┘

[取消] [优化提示词 / 重新优化] [应用到提示词]
```

窄屏使用单列布局，弹窗内部滚动可查看底部操作；支持 Escape 关闭和键盘焦点循环。浅色、深色沿用宿主颜色变量。

## 创作页中的继续调整

```text
提示词                            [我的模板] [参考 e图宝]
┌────────────────────────────────────────────────────┐
│ 当前生图提示词，可直接修改                           │
└────────────────────────────────────────────────────┘
[继续调整] [保存为模板] [撤销提示词优化（应用后出现）]
AI 调整自：模板名称 · 来源 · 原作者链接
```

1. 点击「继续调整」，以当前完整提示词为基础打开优化预览。
2. 输入补充要求，例如「保留人物和装备，光线更自然，减少夸张天空」。
3. 点击「优化提示词」，结合当前轨迹、主体图和效果图改写。
4. 可在预览中手动修改结果；点击「应用到提示词」后更新草稿。
5. 「撤销提示词优化」恢复应用前的完整提示词、模板关联和来源。草稿会保留本次撤销记录。

应用只更新提示词，参考图、图像生成模型与输出参数保留。随后用户自行点击现有「生成图片」。

## 资料和图片的使用规则

- 服务端读取当前轨迹名称、记录统计、最新保存的点位与分组标注，以及所选图片的名称、标签和关联点位。
- 分析所选原图内容，而不仅是文件名。主体图提供人物、景物、装备和构图；效果图提供色彩、光线、氛围与风格。
- 最多 5 张参考图，严格保留创作页展示的角色和顺序。缺失、不可读、跨轨迹或超限时提示处理，不省略图片。
- 先缩小原图至最长边 1280 像素，再交给宿主识图模型；不把视频、音频、案例示例图或未选中的资源交给该请求。
- 有图时只允许宿主明确支持图片输入的文本模型；无图时可选择普通文本模型。可用的宿主默认模型会预选，否则由用户明确选择。
- 轨迹名称和点位说明是用户标注。提示词要求模型区分标注与图像可见内容，不编造天气、地名、通行性、安全或设施；导入时间不作为拍摄日期或季节证据。

## 状态与恢复

| 情况 | 界面行为 |
| --- | --- |
| 正在优化 | 显示进度文字，提供取消优化；保留原草稿 |
| 未配置 / 未登录宿主模型 | 显示宿主原因，暂不可优化 |
| 有图片但没有识图模型 | 提示配置支持图片输入的模型 |
| 原图缺失或读取失败 | 明确报错，待补回或移除后重试 |
| AI 超时、失败或结果不完整 | 保留草稿与原模板，允许重试 |
| 图片、角色、当前提示词、模型或补充要求变化 | 原结果不能直接应用，需要重新优化 |
| 关闭或取消请求后返回结果 | 忽略迟到结果 |
| 应用优化结果 | 写入提示词草稿，保留来源和一次撤销记录，不提交生图 |

## 接口与实现位置

- `GET /api/cqai-track/resource-prompt-models`：模型目录，包含 `supportsVision`。
- `POST /api/cqai-track/resource-prompt-optimize?id=<当前轨迹ID>`：`{model, prompt, requirements?, references:[{assetId, role}]}`，返回 `{prompt, changes}`。
- 前端发送图片资源编号；服务端解析当前轨迹资源并读取图片，不接受前端自定义图片 URL 或 Base64。
- 请求总量最多 128 KiB、提示词最多 20000 字符、补充要求最多 4000 字符；优化总时限为 5 分钟，包含所有参考图预处理与模型返回。浏览器多等待 15 秒接收结果；账号与模型目录查询仍保留 60 秒服务端 / 65 秒浏览器时限。等待时展示实际已等待时长，超过 1 分钟提示仍在处理，可随时取消；不自动重试或更换模型。
- 弹窗与创作页均位于 `cqai-dsh-plugin-track`。模型调用通过已有 `dsnAccount` 服务转发 `/v1/chat/completions`，认证由 DSH 管理。
